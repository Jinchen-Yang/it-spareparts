# 售前重设计原型（只读参考）

这些 `.dc.html` 文件导出自 Artifact 画布「售前询价报价重设计」，是设计组件格式，依赖画布运行时（`./support.js`），**在仓库里打不开，也不能直接复用为项目代码**。

- `R.dc.html`：推荐方案（以此为准）。报价长期有效、主动报价即更新报价、询价人前置、行内直接填写。
- `Main.dc.html`：方向 A，表格直填。
- `B.dc.html`：方向 B，单据分栏。
- `C.dc.html`：方向 C，以型号为中心，按型号合并报价（已否决：同型号重复的只有约六分之一）。

阅读方式：看 `<x-dc>` 里的结构（布局、列、按钮）和 `<script>` 里 `renderVals()` 的交互逻辑，再用 React + AntD 按 [实施方案](../presales-redesign-plan.md) 第 4 节实现。
