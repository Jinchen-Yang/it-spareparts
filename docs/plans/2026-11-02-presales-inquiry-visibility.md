# 询价可见范围开发方案

决策: D-0053

跟踪为 https://github.com/Jinchen-Yang/it-spareparts/issues/511 。

## 当前基础

主线基线为 1d1e618b，当前生产为 release-presales-pool-559489e6-20261102。当前池查询及整单输出采用 D-0052 的全员公开逻辑。系统已保存整单受众规则、实名账号、报价权限和不可变报价修订，沿用这些身份与版本。

## 实现

1. 提供统一的询价 SQL 准入表达式与记录准入方法。菜单、管理员、报价资格、作者和明确授权按同一规则解释；草稿另行收紧。先在查询中应用权限再计数、排序和分页。
2. 新建表单支持可选人员，已提交和已关闭单据有作者或管理员可用的独立可见人员维护入口。使用现有受众数据；接口核对单头版本并记权限变更事件。
3. 池、详情、历史、旧列表、报价库、同 PN 提示、工作簿预览与确认及已有回执共用准入。历史快照不能恢复已撤销的权限，跨询价引用不能将另一个单据的字段带出。
   工作簿每次生成预览时，记录本次从服务器读取的价格来源，随计划摘要持久化。冲突预览中的原值也遵循这份来源授权；后续价格替换不能改变旧回执应检查的来源。
4. 前端提供默认范围说明、可检索的人员多选，保留未提交输入和冲突处理。右上角更新日志说明新可见范围及本轮上线的原需求表功能。
5. 权限回归覆盖作者、被指定销售、普通销售、采购、报价权限覆盖、管理员、无菜单账号、草稿、关闭单据、撤权及旧文件。沿用既有合法流程测试，针对范围变更改写断言。

## 验证及交付

以本轮独立工作树运行定向和完整测试、TypeScript、构建、迁移零漂移和真实浏览器开发验证。跨模型复审后按严格 CI 正常合并。对当前生产到候选的全部变更清单复核，包含已获本轮授权的原需求表 11 项及其必要 Excel 保真依赖。备份和隔离恢复通过后再迁移与切流，保留回滚证据。
