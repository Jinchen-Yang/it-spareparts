## 6. 接口协议：照抄与停笔

协议分三层。第一层已经在代码和 §10 里冻结，后续 PR 不得改字段。第二层是契约 §4 已经写明、尚未确认开工的商城形状，确认后照抄，不得加列。第三层没有规格，本计划不设计。

### 6.1 已冻结：itsp 出站与入站

出站 body 只有这六个字段，多一个就 422，itsp 自己也不发：

```json
{
  "schemaVersion": 1,
  "deliveryId": "<uuid>",
  "unitId": "<int>",
  "partId": "<int>",
  "conditionBucket": "good | bad",
  "qty": 1
}
```

目标：`POST {SHOP_CYCLE_SELL_URL}/api/integrations/cycle/sell-intents`。独立 Bearer。总期限 15 秒，不跟随重定向，`trust_env=false`，响应不超过 4 KiB，`content-encoding` 必须是 identity。

回执 `status`：`applied` | `unchanged` | `blocked` | `conflict`。`unchanged` 只有在该 `deliveryId` 已经持久记过 `applied` 时才接受。以前只是 `blocked` 时，重放不得用 `unchanged`。网络失败、非 200、无效回执保持 `pending`，不写成 `blocked`。

itsp 入站不新增表、不新增列。凭据是 `CYCLE_SELL_CALLBACK_TOKEN_SHA256`（64 位小写十六进制）。空则三个 POST 一律 404 `not_enabled`。摘要不得等于出站 token 的 SHA-256。未知 JSON 字段 422。`Cache-Control: no-store`。

| 路径 | 成功时做什么 | 冲突 |
| --- | --- | --- |
| `POST /api/integrations/cycle/requeue` | body 只有 `deliveryId`。仅 `blocked` 把 `available_at` 调到现在 | 无此 id 为 404。其他状态 200 且不改行 |
| `POST /api/integrations/cycle/mark-sold` | `schemaVersion`、`deliveryId`、`shopOrderLineId`、`qty=1`。`closed` + `to_shop` 改为 `sold` | 同一 `shopOrderLineId` 第二次 200 且不写第二笔。其余 409 `remote_conflict` |
| `POST /api/integrations/cycle/revert-sold` | 只把 outcome 从 `sold` 改回 `to_shop`，工位保持 `closed` | 行号不一致、或已发货退货误调用，409 |
| `GET /api/cycle/units/{id}/sell-intent` | 用户 JWT，仅 `page_cycle_manage`。响应等于 `read_status()` | 无权限 403，单位不可见 404 |

itsp 库表维持 #528 的三张，本计划不加列：

| 表 | 关键约束 |
| --- | --- |
| `maintenance_cycle_unit` | 工位 `pool/testing/repairing/outsource/ready/closed`。结案 `to_shop/to_company/scrap/sold`。一行一件 |
| `maintenance_cycle_event` | 售出幂等靠事件 payload 里的 `shopOrderLineId` |
| `maintenance_cycle_sell_intent` | 一单位一条。状态 `pending/delivering/delivered/blocked/failed`。`qty` 只能是 1 |

返还收货入池沿用现有 `HandoffInput`，不改形状：

| 字段 | 规则 |
| --- | --- |
| `receipt_id` | 1–36 字符。收货行须 `active`，`part_id` 指向 active 备件 |
| `qty` | 服务层校验 1–1000。越界 400。已入池未撤回件数加本次不得超过收货数量 |
| `expected_receipt_version` | 与收货行版本不一致则 409 |
| `serial_numbers` | 可空。与 `qty` 等长，同一收货行 SN 重复则 409 |
| 权限 | `page_cycle_recycle` 或 `page_cycle_manage`。201，body `{items}` |
| 额外字段 | 422 |
