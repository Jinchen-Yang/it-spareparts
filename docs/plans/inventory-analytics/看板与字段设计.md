# 库存管理分析 · 看板与字段设计

2026-11-20。出库来源见 D-0066。候选入口为「库存管理 → 库存管理分析」，路由为 `/inventory/analytics`。导入字段、来源状态与更新语义见[来源接入](./来源接入.md)，上线前用库房原单逐项验收。

## 管理层和库房各看什么

| 看板 | 要回答的问题 | 指标、维度和下钻 |
| --- | --- | --- |
| 收发总览 | 今天和本周哪类业务最忙，哪个仓集中收货或发货？ | 按业务日期画日、周柱图或折线，按来源并列单数、行数和指定单位量。仓储中心、业务类别可继续筛选。点击日期进入该来源的单据与匹配行。 |
| 人员工作量 | 工作集中在哪些人、哪些日期？大单多还是处理型号杂？ | 按岗位展示单据数、明细行数、不同 PN 数、指定单位数量及有业务记录的天数。各指标独立排序，同值并列。个人节奏按日或周一开始的自然周钻单。实际拣货、直退经办、测试、出库岗位分别归集。 |
| 退货 PN 聚集 | 哪些型号在多张退货单上反复出现？集中在哪些类别、品牌或中心？ | 默认取返库单中“销售退货”的备件明细。可切全部返库或直退。前十 PN 行占比用前十型号的明细行数除以窗口内有 PN 的明细行数。重复 PN 至少出现在两张不同源单。提供单数、行数、指定单位量和 PN 描述。支持展开单型号的仓储中心 × 最近八周，核对集中出现的时间与地点。 |
| 交叉矩阵 | 哪个仓、岗位、品类或型号的组合最突出？ | 可交叉中心、来源、业务类别、人及岗位、PN、大类、品牌、作业仓库、可读库位、单位、测试结果。全筛选范围聚合后取 Top。交叉格和边际分别去重，点格子继续看同一范围的货品行。 |
| 整机与备件 | 哪些整机带来的子件处理多？ | 单头数、整机 PN 和描述、按整机单位分列数量、匹配子行数、子行 PN 和最近日期。按子行筛选时只展示包含这些子行的整机单头，一次计头。 |
| 测试与覆盖 | 哪个中心待测量高，已完成的记录里有多少能归到实际测试人？ | 需测单作分母，细分记录为完成、待测及状态缺失。按业务日期选单查看导出时状态。按完成日计算个人测试完成量是另一时间口径。列出各来源的首末业务日与所选窗口的交集。 |
| 单据与货品 | 一个数字由哪些单据、哪些 PN 构成？ | 来源、业务单号、业务日期、中心、实际岗位、匹配行数、分单位量和 PN 描述。悬停单号看当前匹配的货品，单内保留原单总行数作参照。 |
| 实际出库 CKD | 实际从哪里发出了什么，由谁处理？ | 以 CKD 实际出库日期、类别、中心、仓库/库位、实际拣货或发货人、PN/描述、SN、单位、出库数量展开。接入完整范围后进入总览、个人日周榜和矩阵。 |

## 读数规则与界面行为

- 默认按上海业务日含今天的近 30 天，可改日历区间。该附件各源日期不齐，可快捷选样本末 30 天、三表重叠期和全部样本。在来源首末日内无匹配单据只代表附件查询结果。缺少 CKD 或选区在来源范围外显示覆盖说明。
- 样页按已生效状态、来源单头 ID 和子行 ID 识别单据与明细。下钻保持当前页的中心、日期、岗位、单位和 PN 条件。单据去重后分页，再取对应行。返回上层、浏览器后退和刷新保留当前上下文。
- 备件数量以本行实际业务数量求和。保留原单位、缺失、真实零以及整机的独立粒度。多人名单可作为覆盖维度；实名缺失时不能分摊个人工作量。
- 入库来源里的退货/维保返件可能触发返库子流程。同一来源内部去重可以核对作业单量；跨来源合计仓库实物流量，需要原始关联键、流转阶段以及配对验收。销售退货、维保返件与直采直退分别看。故障率、退货率、库存余额需要各自可核实的归因、发出基数或库存快照。
- 建议以日期、中心、业务类型、来源、角色、货品原单位和 PN 做共享筛选。仓库、库位、品牌、结果以及受权的关联单号可用于下钻。SN 和自贴码适合串行核对；在覆盖率和关联关系确认前，重复 PN 不等同于同件多次返回。

## 正式接入与验收

附件含辅助 sheet、多层表头、纵向合并单头、同名列和外链元数据。正式导入建议使用来源版本加命名 sheet 的白名单模板，按数据行及字段标识取已保存的值。重复导入、变更批次和作废都须隔离原始记录与当前事实。维保应用接口有业务副作用。分析读口应使用独立只读投影。

现有库存快照/动态库存、维保 CKD 暂存、维保仓单查询分别覆盖不同业务范围。全仓日周报表需要完整 CKD 对账与读权限。建议沿用采购分析的控件、权限感知会话缓存和历史路由，服务端聚合排行、交叉格、独立合计，汇总和详情分请求、按页返回。班次工时、多人分摊规则、跨源物理收货配对及出库源岗位字段是正式接入的待核项。

验收用同一单含多 PN、多单位的源单逐格对拍，验证多人名单、跨周、未覆盖期间、整机子件与取消单。对比日周单数、行数、同单位量、前十 PN 的分母与单据明细，并检查角色及数据权限在图、浮窗和详情中的一致性。
