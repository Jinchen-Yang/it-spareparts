# 售前询价列表查询

`GET /presales/inquiries` 在既有 `kind`、`scope`、`status`、分页与排序参数之外支持：

| 参数 | 格式 | 行为 |
|---|---|---|
| `q` | 最多 256 字符，默认空 | 去掉首尾空白，以参数化 `ILIKE` 搜索单号、活跃询价行的 PN 原文和描述、绑定主数据的 PN 和描述，以及有权查看的客户原名和规范名 |
| `date_from` | `YYYY-MM-DD`，可省略 | 最近更新时间不早于该日上海时间 00:00 |
| `date_to` | `YYYY-MM-DD`，可省略 | 最近更新时间早于下一日上海时间 00:00，即包含所选结束日 |

`q` 中的 `%`、`_` 和反斜线按字面匹配。日期可仅传一端；开始日晚于结束日返回 422。先进行 SQL 搜索、日期筛选和白名单排序，再应用原有记录可见性、`scope` 和分页；返回的 `total` 与同一筛选范围一致。

列表项增加两个字段：

- `customer_name: string | null`：沿用询价输出的客户权限，须有 `data_customer` 且是单据所有人或主管；不可见时为 `null`。名称优先使用非空规范名，回退原名。客户搜索采用同样的权限范围，避免通过匹配结果推断别人单据的客户。
- `is_owner: boolean`：当前账号是否为发起人，供销售汇总选择控制使用，不返回被隐藏的其他账号 ID。`scope=mine` 同时包含本人发起和本人被指派的单，不能用该范围代替所有权判断；汇总导出仍在后端复查所有权。

前端搜索在最后一次输入 300 ms 后发送请求。日期筛选和搜索结果由接口决定；列表直接显示 `customer_name`，不依赖采购分析选项接口。
