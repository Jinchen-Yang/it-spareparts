【任务】把维保前端从 22 页收敛为 2 页：维保主页（项目卡墙）+ 项目面板。旧页面删除代码，新页面直接替换上线。

【第一步：先读这些文档（都在你当前分支上，按顺序读）】

6. docs/api/维保后端接口文档.md 与 docs/api/maintenance-routes.tsv —— 你自己写的接口清单

【目标页面】

页面一：维保主页（项目卡墙，路由建议 /maintenance）
- 顶部筛选：项目类型（默认「进行中」，可切「已结束」）、状态（正常/提醒/报警）＋模糊搜索框（搜项目名、XSDD 单号等）。
- 项目卡一行 5 张，下滑无限加载。
- 每张卡：项目大标题；XSDD 合同号；项目经理、合同总额；小字＝备件成本（含税/未税）、缺失成本、维保备件采购数、回款预览；进度条（v1 仅一条＝成本÷合同额：<80% 绿、80–100% 黄、>100% 红）；底部「进入面板」按钮。
- 卡片三态＝进度条颜色：正常=绿、提醒=黄、报警=红。原 AB-2「需关注」队列不再渲染独立栏目：超预算本身就是黄/红状态；待返件多作为卡片上的文字提示（小字）。
- 主页全局下载：所有项目的备件行级表（系统自动回填价后），时间预设 今天/昨天/本周/本月/自定义；改价/补价后上传覆盖＝真实源（新端点，见下）。

页面二：项目面板（点「进入面板」）
- 顶部：出库明细＝现在生产版本的内容，按时间筛选；一个项目多张合同时可并排显示或筛选只看某一张（数据可用你 boss-board 下钻已有的单据/PN 证据数据改造）。
- 子顶栏 tab：项目基础信息（表 6 sheet 01 的 web 呈现）、备件成本（03）、报销（04）、回款（05）。
- tab 栏右侧：下载本项目总表（六 sheet 工作簿），回填后上传覆盖。
- 每个 tab 页内：单独下载对应 sheet，在哪下载就在哪上传。
- 项目名旁编辑入口：改项目基本信息（起止时间、负责人等），与 sheet 01 联通。
- 归属挂靠也在这里：项目面板「基础信息」tab 点确认挂靠；对不上任何销售订单的单子才独立成项目。

【后端要求】
- 优先复用已有端点；确需新增的只有：①全项目备件行级表导出（日期区间参数，含 今天/昨天/本周/本月/自定义 语义）②项目总表六 sheet 下载 ③各 tab 单 sheet 下载 ④对应上传覆盖端点（沿你 AB-3 已建 maintenance_expense_collection_workbook 的模式扩展，不要另起炉灶）。

- 归属候选/确认沿用既有 assign 端点；预交付剥前缀沿用 project_names 单一真值。
- 原始单据上传（需求单/发货/返库/入库/台账）不动：继续走 admin「数据中心→数据导入」，不新建上传台。
- 旧前端页面删除后，旧后端端点暂时保留不删（避免误伤 AB-1~4），后端清理另行安排。

【写死的口径（不许改）】
1. 归属判定＝XSDD 销售订单：同一销售单＝同一项目，不同销售单＝不同项目；唯一例外＝多合同项目（如「兵装财务20240701-20250630北京神州新桥 整体维保」）按台账项目名聚合。
2. 维保备件采购数＝需求单里已发货/已确认的数量（库房发货＋直采直发）。
3. 成本字段名「已知申请估算成本(含税)」，键 known_apply_cost_inc_tax。
4. 状态列（已采/待供/待返/领用）只展示不计算不标注。
5. 事实源分离：实发=发货单；未用件收回=返库单（成品）；坏件回收=入库单（坏品/废品返件类）。
6. 缺数据绝不隐藏、绝不按 0：未导入显示「尚未导入」、无参照价留空标注、PN 未标准化池归属显示「—」、无金额权限显示受限块。
7. 缺价/报销/回款的一切修改只走「下载 Excel→改→上传覆盖」，系统内不提供手工散改表单。
8. 权限：主页/面板 anyPerm=[page_maintenance_boss, page_maintenance]；金额字段挂 data_purchase_cost/data_profit；下载上传走既有动作键。
9. 销售/采购/库存模块与冻结清单 9 项一律不碰（购物车已解冻按 AB-4 现状保留）。

1. 后端端点补齐＋测试 → 2. 主页 → 3. 项目面板 → 4. 删旧页＋导航重写（nav.tsx 单一真值源）＋重定向 → 5. 全量验证：pytest 全量 + 前端 tsc && vite build → 6. 推送到当前分支 claude/web-github-capabilities-x7kfh7。
