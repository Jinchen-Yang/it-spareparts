# DEV-03 / DEV-04 互通池价格分析验收记录

## 结论

本功能只复盘已经发生的采购与销售，不参与报价、询价、下单或审批。所有池价格、人工约束价、差额和越线状态统一受 `data_pool_price_governance` 控制；供应商和客户分别继续受原有数据权限控制。

## 数据与性能基线

- 数据来源：生产数据库备份恢复到独立本地数据库 `spareparts_dev03_stage`，未连接或修改生产数据库。
- 样本规模：40 个有效池、586 个池成员、88,167 条采购明细、130,273 条销售明细。
- 互通池清单 p95：59.53 ms，门槛 `< 300 ms`。
- 单池 365 天详情 p95：124.95 ms，门槛 `< 800 ms`。
- 50 个 PN 批量参考卡 p95：67.05 ms，门槛 `< 300 ms`。

## 功能验收

- 全员入口：左侧「价格分析 → 互通池」。
- 时间范围：近 30 天、近 90 天、近 365 天、全部及自定义日期。
- 池清单：采购/销售均价、中位价、订单数、明细数、人工约束价。
- 池详情：采购/销售方向、成员价格排名、成员卡片、逐笔订单、完整订单内容。
- 参考卡：型号查询、采购分析、采购明细使用同一后端批量接口，不在前端重复计算。
- 深链：池、方向、时间范围和 PN 可通过 URL 保存和返回。

## 权限验收

- 开启池价格纪律：可见历史采购/销售价格、池均价、经办人、人工约束与越线事实。
- 关闭池价格纪律：价格、约束、差额、越线状态、价格排序全部隐藏，不能通过顺序或颜色反推。
- 供应商权限关闭：供应商隐藏，但经办采购员仍可见。
- 客户权限关闭：客户隐藏，但经办销售员仍可见。
- 订单详情走互通池专用端点，不复用老板经营看板权限。

## 响应式与可访问性

- 1440px：完整表格、图表和订单详情正常。
- 390px：`scrollWidth = clientWidth = innerWidth = 390`，无整页横向滚动。
- 390px 成员与订单使用卡片，不渲染桌面宽表；卡片支持 Tab、Enter 和 Space。
- Enter 打开成员全屏详情已真实浏览器验证，包含采购/销售均价、数量、与池均差额及人工约束价。
