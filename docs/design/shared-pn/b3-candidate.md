# B3 统一授权与交互接入候选

本候选将共享 PN 接入指定权限会话的 S1 框架，并提供 ITSP 主资料、好坏件通用描述、图库、候选和审计维护界面。Shop 继续适配原有交互；完整收件箱工作台、自定义参数迁移及最终统一验收仍由后续候选完成。默认关闭，未操作生产。

## 依赖与分支

- 设计决策：D-20261023-PN；权限决策：D-0026。
- 基于 B2 #470，并集成 S1 `bad6976` 及后续权限迁移边界修复。S1 属于独立权限会话，不能把本 PR 当作对该会话所有模块的验收。
- 本 PR 是堆叠 Draft。B2 和权限依赖进入 main 后，应重新对齐 main、收窄差异并重新跑完整 CI，再讨论合并。

## 本批行为

- VerifiedIdentity → 当前账号版本 → Grant → Cerbos；native 与 Shop 短期委托共用授权判断。证明绑定方法、原始路径和查询、body hash、请求 UUID、If-Match；数据库 nonce 阻止重复交换。
- 旧维护、导入、别名/合并/规格补全入口在持久切换后不能绕过新权限。导入记录实际提交账号版本，并在变更实际字段和派生规格前校验。
- GET /access、逐 PN access、只投影可读字段的目录、有界本人任务历史；旧静态目录令牌在接管后失效。
- 创建与精确外部 UUID 绑定同事务；已有 PN 显式选择后也能建立不可变来源绑定。原绑定保留，canonical 变化单独显示，绝不按相似名称认领业务数据。
- POST /parts/lookup 使用权威规范名和生效别名；待审别名、多个身份或人工 PN 与导入规范化冲突均明确返回 ambiguous。
- 实际 OSS 分片查询释放数据库连接后出网，再校验原操作版本及授权；收件箱保留原文件信息、拍摄顺序和当前有效识别提示。
