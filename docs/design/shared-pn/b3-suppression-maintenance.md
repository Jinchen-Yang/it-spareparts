# B3 共享图库隐藏与恢复

决策：D-20261023-PN。

隐藏规则按图片内容 hash 作用于当前共享图库的全部来源与用途，不删除原文件，不更改图片来源归属。取消隐藏只移除显示规则，不能复活被删除的图片。两端图库提供相同的隐藏原因、当前隐藏列表和恢复显示入口；删除记录仍独立维护。

`GET /gallery-groups/{group_id}/suppressions` 仅投影 active 规则的 id、group id、内容 hash、原因和版本，不返回对象存储 key、地址或任务输入。默认每页20、上限50，以 UUID keyset 分页；游标绑定当前主体、客户端、全部来源权限和图库版本。图库或授权变化需重新读取，不拼接旧分页。

列表、隐藏、恢复和命令回执都重验当前 group 的全部 origin PN 权限。读需逐来源 gallery.read 与 gallery 字段；写还需对应 suppress/unsuppress 字段写权。锁顺序为 topology shared → 全部来源 PN 排序读锁 → group 读/写锁；空成员的退休组拒绝操作。显示根 PN 的权限不能代替其他来源权限。

隐藏使用操作者看到的图库 revision，恢复使用该规则 revision。网络失败或5xx时界面冻结原路径、正文、版本和幂等请求号；明确冲突时保留草稿并提示刷新核对。新读取失败清除旧隐藏规则详情，不能保留撤权前的内容。界面不会向外部存储请求隐藏图片预览。

隔离 PostgreSQL + HTTP 覆盖安全分页、仅元数据、全部来源读写权限、回执撤权重验、游标与主体/权限/图库版本绑定、退休组以及旧版本恢复冲突。两端界面覆盖未知响应的原意图重试与撤权清除；原图库排序/展示回归继续执行。所有验证使用本地测试数据库，未操作生产。
