# DEV-05B1 规则校准预览——验收记录

## 结论

DEV-05B1 满足合并条件。它是纯只读的采购相邻价格规则模拟器，不是自动检测器：不会保存阈值、生成数据疑点、写审计或修改采购、销售、利润、库存、互通池和员工排名。

本版本无数据库迁移。合并后仍需在生产快照或 staging 复核查询性能与权限，满足发布门禁后才能部署。

## 交付边界

- 固定比较 2、3、5、10 倍四档。
- 只比较已生效、非未来、同 `part_id + 采购类型`、正数量和正价格的相邻采购行。
- 日期窗只限制本次采购，窗前最近一笔仍可作为前值。
- 复用正式未税采购价口径；保留高精度 NUMERIC，避免精确 2 倍被算成 1.9999。
- 展示采购类型、涨跌方向、候选规模、候选率和确定性样本。
- 同时要求数据治理页面与采购成本查看权限；缺权限整体 403。
- 不返回供应商、客户或经办人。
- 单次查询事务局部超时为 3 秒，超时回滚并返回可重试的 503。

## 性能和失败边界

- 生产快照单次查询约 0.36–0.39 秒。
- 五并发实测约 0.35–0.39 秒，满足 p95 小于 1 秒的阶段门槛。
- 请求事务内 `statement_timeout=3s`，回滚后连接恢复为 0，不污染连接池。
- 将保护时限临时降到 1ms 可稳定触发超时；API 返回 503 且不暴露 SQL。
- 四个倍率共用同一个 MATERIALIZED 相邻对计算，不扫描四遍事实表。

## 权限与浏览器验收

- 有治理页面且有采购成本权限：接口 200，可见四档和样本。
- 缺采购成本权限：接口 403，响应不含倍率、排序或价格。
- 桌面 1440px：四档卡片、前后两笔日期/数量/单位/税口径、采购类型分布完整，无整页横滚。
- 手机 390px：无整页横滚，不渲染宽表；阈值两列、分布和样本使用卡片；样本每页 10 条，避免一次铺开 48 张长页面。
- 页面没有启用规则、保存阈值、确认错误或批量生成疑点按钮。
- 加载失败会清空旧结果；快速切换筛选时旧响应不会覆盖新结果。

浏览器证据：`/tmp/dev05b-calibration-1440.png`、`/tmp/dev05b-calibration-390.png`（本地验收产物，不进入仓库）。

## 生产发布门禁

1. 精确部署合并后的 `main` SHA，保留旧镜像回滚标签。
2. 在生产快照或 staging 重跑独立 SQL，四档计数与接口一致。
3. 五并发 p95 小于 1 秒、p99 小于 2 秒；确认超时为 3 秒且连接池恢复。
4. 用有权限与无成本权限账号分别冒烟，确认 200/403 和无信息旁路。
5. 请求前后疑点、审计和核心业务表计数或摘要不变。
6. 前端版本为 v1.16.1，桌面和手机至少各验收一次。
7. 上线后观察错误率、数据库慢查询和连接池至少 30 分钟。
