## 结论

「期限缺失」有两层根因，已分别处理：

1. **判定层**：期限完整但尚未开始的项目被兜底判成 missing；成本页/看板另有一套
   只看 WBDD 单 `maint_end` 的实现；展示侧还在读不会自动刷新的存库快照。
   —— 三处已修（见 `maintenance_periods` 与 `maintenance_cost` 的 2026-09-03 改动）。
2. **数据层**：WBDD 自动建项的期限是**从项目名正则抠日期段猜**的，销售订单上的
   权威日期从不参与。—— 修法是按 XSDD 建项，期限/名称/负责人直接取销售订单列。

口径：只有「维保业务=是」且「数据状态=已生效」的销售订单行自动建项；期限允许
缺失或单侧（D-05：销售订单上没有期限的留给人工在项目信息编辑里填），单侧会显示
「期限缺失」把待补项目筛出来。
