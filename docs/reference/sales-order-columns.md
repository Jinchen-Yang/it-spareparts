# 销售订单导入字段口径（氚云导出）

- 依据：真实销售订单样例 `销售订单_2026-09-02-09-49-37-421.xlsx`（156 列，双表头：第 1 行英文字段名 / 第 2 行中文列名）。
- 订单编号格式：`XSDD-YYYYMMDD-序号`（如 `XSDD-20260828-0120`），氚云自动生成，人填不了。

## 建维保项目要用到的关键列（都在销售订单里，main 导入映射尚未接）

| 中文列名 | 字段名 | 用途 | 现状 |
|---|---|---|---|
| 订单编号(必填) | `SeqNo` | 项目身份（XSDD），归一化后唯一 | 已映射 `order_no` |
| 维保起始日期(必填) | `F0000131` | 项目 `period_from` | **未映射，靠从项目名猜** |
| 维保终止日期(必填) | `F0000132` | 项目 `period_to` | **未映射，靠从项目名猜** |
| 项目名称(必填) | `F0000119` | 项目显示名 | 未映射（现从需求单名猜） |
| 项目经理(必填) | `F0000134` | 项目负责人 | 未映射（现人工指定） |
| 最终客户名称(必填) | `F0000120` | 维保实际客户 | 未映射 |
| 业务类型# | `F0000059` | 判断是否维保订单（备件维保 / 整体维保） | 已映射 `business_type` |

样例值（脱敏后）：维保起始 `2026-09-01`，维保终止 `2027-08-30`；订单编号 `XSDD-20260828-0120`。

## 结论

「期限缺失」的根因是：**销售订单上有维保起止日期（必填列），但导入映射没接，项目期限退化成从项目名里猜日期段**。修法是给 `f_sales_order` 补维保起止/项目名称/项目经理列，映射接上，维保类订单按 XSDD 建项直接取用。`codex/sales-xsdd-auto-project` 分支已加了期限两列映射，思路正确，需从大分支切出。
