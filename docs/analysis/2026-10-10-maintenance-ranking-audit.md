## 研究依据

PostgreSQL 默认 Read Committed 中，单条 SELECT 看到的是该语句开始时的快照；同一事务内的下一条查询仍可能看到其他事务新提交的数据。因此只把多次查询包在普通事务中并不能保证图表一致。新统计读模型将规范事实和分组汇总放在一条 SQL 内；权限查询不作为另一个业务总计来源。参见 [PostgreSQL 事务隔离文档](https://www.postgresql.org/docs/15/transaction-iso.html)。

图形事件需要携带业务实体身份，不能由屏幕标签反推；图形还需要文本、键盘入口和数值信息，颜色不能独自承担身份或数值表达。研究了 [ECharts 事件模型](https://echarts.apache.org/handbook/en/concepts/event/) 与 [无障碍指南](https://echarts.apache.org/handbook/en/best-practices/aria/)。本次正式组件可采用原生按钮、SVG 和表格实现同等交互，不新增可执行 HTML tooltip。
