## URL 与历史约定

所有本次状态更新用 replace，包括治理标签页。MaintenanceHomePage 当前 patchParams 为 replace，没有标签切换 push 惯例。后退跳回上一导航条目，不逐个撤销筛选；离页再后退则恢复离开前最后一次筛选。多字段变化一次 patch（React Router 同 tick 的 setter 不提供 setState 式队列）。

仅读声明键，缺省/空/非法回退默认；读取不主动改写地址。写入指定键时删除默认/空/非法值，保留其他键（含重复无关键）。关键词按原值传 API，不新增 trim 规则。页码仅正安全整数，默认 1；分页大小保持 20。利润维度按当前账号可用选项校验，异常仅在当前权限允许时应用；日期要求完整有效 YYYY-MM-DD 且起始不晚于结束，否则整个范围回退不限日期。

MaintenanceHomePage 的业务类型 CSV 与权限默认值、显式 all、未归一 URL 等历史兼容规则较多；若共用 hook 会改变其行为，则本次保持原样。
