# D-0062 下载表格账号列统一附显示姓名

- 日期：2026-11-16。
- 编号：D-0062。文件 `docs/decisions/0042-下载表格账号附显示姓名.md`。
  前一号为 D-0061（`0041-检测与维修统一模块.md`，在途未合并）。
- 来源：PR #544；甲方 2026-11-16 要求「项目总表所有出现账号的地方后面都加上
  对应账号的姓名，其他有下载表格的里面都这么实现」。
- 状态：代码随 PR #544 合入 main；未上线，生产以 `release-` 标签为准。

## 决定

1. **下载导出文件中的人员账号列统一显示「账号（姓名）」**（全角括号，账号在前）。
   账号无显示名（含 RKD 导入占位账号 `rkd_import`、系统占位账号）时**原样保留账号，
   不臆造姓名**，延续 D-0025 的登记人显示名解析口径（`sys_user.display_name`，
   停用账号照常解析）。
2. **覆盖出口（四处）**：
   - 项目总表（V2）「返还收货台账（只读）」的「登记人」列；
   - 项目清单导出（boss board `POST /projects/export`）的「维保负责人账号」列；
   - 维保看板 `export?kind=receipts` 的「登记人」列；
   - 项目经理月度工作簿 V3「03_验收材料」的「审批人（只读）」列。
3. **Supersede（部分）**：D-0025 决定 3 中「导出新增『登记人』列（有显示名为
   『显示名（账号）』，否则账号）」的**导出文件格式**由本决定改为「账号（姓名）」；
   D-0025 其余内容（Top 40、登记人汇总与筛选、`created_by` 语义、权限模型）
   不变。**页面 UI 展示不在本决定范围**，`ReceiptsDrillDrawer` 等仍按 D-0025
   原口径（「显示名（账号）」）执行；如需统一另行拍板。
4. **只读校验兼容**：项目总表台账哈希与 V3 验收 sheet digest 均为**文件内自包含**
   （下载时写入文件 meta，上传时与文件自身内容比对，不与数据库重算快照比对），
   显示格式变更对新旧文件的下载-上传闭环均无影响；旧格式文件重上传不受本决定影响。

## 事实说明

- 项目清单导出的「维保负责人」列（姓名）与「维保负责人账号」列本就并存；
  本决定不合并两列，账号列内附姓名仅便于脱离系统辨认操作人。
- `01_项目概览` 的「项目经理（负责人）」为仅显示名呈现（无姓名回退裸账号），
  属页面级只读展示而非账号列，不在本决定统一范围内。
