# D-0057 坏件循环池与闲鱼可售意图

- 日期：2026-11-07（America/Los_Angeles；仓库日历日 2026-11-08 UTC）。
- 编号：D-0057。文件 `docs/decisions/0037-坏件循环池与闲鱼可售意图.md`。起草时曾暂用 D-0056，因 #517 已占用 D-0056（`0036-需求口径确认.md`）顺延为 D-0057，口径不变。需求登记为 [需求00014](../requirements/需求00014.md)。
- 来源：2026-10-26 系统优化与维修数据管理讨论；2026-11-07 流程拍板（成品入池、修好可选再测、氚云不动、委外回来手选、一类一贴、全自动上架）；2026-11-08 杨金臣补充第 7 条，原话：「用闲管家就行。不需要员工手动发布。一类一贴数量就1就行。卖出去了重新挂一条就行。」
- 状态：已确认，授权本轮后端编码。前端页面由另案实现，本条只定后端事实与接口口径。

## 背景

维保返还收货台账（`maintenance_rkd_return_line`）只回答「收到了什么」。检测、维修、委外、报废、回公司、去电商不在现有状态机内。商城目录同步只建好坏零库存 SKU，不能驱动闲鱼上架。本条把「循环单位」和「可售意图」定为独立经营事实，不改氚云进销存。

## 决定

1. **循环单位是处置主键。** 新建 `maintenance_cycle_unit`（对外 `unit_id`）。一件或一次入池确认的整数数量对应一条单位行；入池数量必须为正整数。稳定身份用 `part_id`（`dim_part.id`）；`pn` 文本仅快照。`part_id` 未解析的收货行不得入池。
2. **成品/坏品/废品均可入池。** 入池来源：返还收货台账交接入池，或外部坏件直建（不挂项目）。收货行上的 `test_result` 只作入池件况快照，不充当处置状态。
3. **工位与终态分离。** 工位：`pool`（回收池）、`testing`、`repairing`、`outsource`、`ready`（待选终态）、`closed`。终态 outcome：`to_shop`、`to_company`、`scrap`、`sold`。修好后可选再测（回 `testing`）或不测（进 `ready`）。委外回来必须手选下一跳：`testing` / `repairing` / `to_shop` / `to_company` / `scrap`，无默认自动分流。
4. **氚云零写入。** 循环池任何动作不得写 `inventory`、`stock_dynamic`、前置库、采购单、销售单。回公司只记 outcome 与交接备注；报废只记 outcome；去电商只发可售意图。
5. **权限按角色裁字段。** 新页面键：`page_cycle_recycle`、`page_cycle_test`、`page_cycle_repair`、`page_cycle_manage`、`page_cycle_wip`。检测/维修账号不得通过接口读到项目、客户、委外供应商名；供应商名仅 `page_cycle_manage` 可见。不复用 `page_maintenance` 作工人导航。在制数量不得写入 `/parts/overview`。
6. **可售意图独立投递。** 点 `to_shop` 时写入 `maintenance_cycle_sell_intent`：`partId` + `conditionBucket(good|bad)` + `qty` + `deliveryId` + `unitId`，不带项目、SN、维修备注、内部成本。全自动上架：本仓不等人确认；商城缺类目映射或缺正式图时意图进入 `blocked`，补齐后继续自动投递，不改回人工草稿页。
7. **一类一贴，单件链接，售出重挂（2026-11-08 补充）。** 发布通道用闲管家，由商城自动发布，员工不手动发布。同 `part_id` + 同 `conditionBucket`（合帖键为 PN 身份，不是 `category_major`）在闲鱼上同时最多一条在架链接，链接库存恒为 1；同键其余可售件在商城排队，不同时挂多条同款。在架链接绑定一个具体 unit。该链接售出后，商城把这个 unit 回写 `sold`；同键仍有排队件时自动新挂一条库存 1 的新链接，无排队件则不挂。
8. **售出回写。** 回写按具体 `unitId` 标 `sold`；不写 `maintenance_bad_salvage`，不建闲鱼售后闭环。

## 不变

- 返还收货台账 `active/voided` 与件况枚举不变；入池后改收货数量/作废若 unit 已离开 `pool` 且非可逆草稿态，返回冲突，不静默改历史。
- D-15 搁置的返还单状态机、D-36 目录同步零库存建品、变卖登记「不伪造采销单」继续有效。
- AI / 智能体不得写循环工位或 outcome。

## 验证

- 契约测试：工人账号列表与详情不含 `vendor_name`、项目字段；氚云库存表在循环动作前后行数与结存不变；`to_shop` 必产生意图且 payload 无项目/SN；版本冲突 409。
- 本决定不授权生产部署。
