# D-0047 售前询价优先级、催办、坏件是否返回与报价价格性质

- 状态：已确认。需求由宋丽芳（采购）2026-10-29 在「备件智能体」群提出；口径由杨金臣 2026-10-29 逐项拍板。
- 日期：2026-10-29（Asia/Shanghai）。
- 范围：售前询价单、询价行与报价的新增字段和「催办」动作。补充 D-0046，不改变其报价有效期与主动报价口径。

## 决定

1. **优先级两档：普通 / 紧急。** 询价单头字段 `priority`，取值 `normal`（默认）或 `urgent`。销售新建或修改询价时可选；采购报价页紧急单标红并排在前面，同优先级按时间排序。存量询价一律视为普通。
2. **坏件是否返回：每行一个，默认返回。** 询价行字段 `return_defective`（布尔，默认 `true`）。销售在询价行上勾选；采购报价行、询价详情直接显示「坏件返回 / 不返回」。存量行按默认值「返回」处理。
3. **催办：销售催未回复的单，30 分钟限一次。**
   - 只有询价发起人可以催办；询价须为「已提交」，且仍有未完成的采购待办（即还有行未回复）。
   - 同一张询价两次催办间隔不少于 30 分钟，过早再催返回冲突并提示还需等待的时间。
   - 催办记入询价时间线（`inquiry.urged`），单头记 `urge_count`（累计次数）与 `last_urged_at`（最近一次时间）。
   - 系统目前没有消息推送：催办以采购报价页上的「已催 N 次」红色标记与置顶呈现，不新开待办、不改变处理人。
4. **报价区分成本价 / 售价，所有人可见。** 报价字段 `price_basis`，取值 `sale`（售价，默认）或 `cost`（成本价）。采购报价时选择；价格性质只是标注，不做额外可见性限制，可见范围仍按报价已有的受众规则。存量报价视为售价。

## 不变

- 报价长期有效、主动报价、询价人前置等 D-0046 口径不变。
- 优先级不改变派单与公共池规则；催办不改变待办状态与处理人。

## 验证

- 后端：新字段可在新建/修改询价、报价保存与更新时写入并在详情返回；催办的发起人、状态、30 分钟间隔校验；存量数据按默认值返回。
- 前端：询价页可选优先级、每行勾选坏件返回、对未回复的询价催办；报价页按紧急与催办置顶并标记，报价行可选成本价 / 售价，销售侧显示价格性质。
- 一次数据库迁移（新增五列、带默认值，不回填业务数据）。完成本地回归后由用户安排点按验收；本决定不授权生产部署。
