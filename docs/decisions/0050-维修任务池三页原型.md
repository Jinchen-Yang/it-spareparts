# D-0070 维修任务池三页原型

2026-11-19，用户确认页面组织并要求先看可点击原型。流程讨论见 [Issue #549](https://github.com/Jinchen-Yang/it-spareparts/issues/549)。

- “检测与维修”原型设 **维修任务池、我的任务、分析** 三页。维修任务池内切换任务总池和公共池。
- 销售和维修主管在维修任务池创建维修单。销售可直接派给维修人员或投入公共池，主管可分配任务，维修人员可从公共池自行领取。上述内容更新 D-0061 的五页签和公共池只读约定。
- 总池按角色展示可见任务。承办人在我的任务中按任务条登记委内或委外维修结果，管理员在原任务详情办理去向。
- 为便于点按，先演示整单一人承接、任务条分批出结果，以及自领后由管理员在领取记录所在的原单决定去向。这些是待评审交互。电商在本原型中仅记录模拟去向，二次维修以关联的演示任务单回池。
- 上游单据如何接入、旧循环业务如何衔接、正式授权和数据架构另行讨论。本次授权仅及本地原型。

## 点按后的修订

- 创建人在建单时决定委内或委外。本版按整张维修单选择一次，承办人可查看该方式。
- 维修人员可领取公共池的单，办理本人任务时填写修好、没修好的数量，也可选“我修不好，退回主管”。退回把原单交给维修主管，记录历任负责人。主管从“我的任务”处理退回单，可修改后重新派给维修人员。
- 主管可修改所有维修单的数据，包括明细数量、修好和没修好数量，已登记结果的单据也可打开修改。单号和历次负责人记录用于追溯。
- 这版点按采用两项演示约定：已部分登记的单退回时保留既有结果，剩余数量交给主管；主管更正结果时，同一结果已登记的模拟去向数量要与更正后数量相符。
