# D-41 销售分析页与销售单金额

- 日期：2026-10-17。
- 来源：杨金臣对《itsp 客户需求 Round1 开发计划》的答复（2026-10-17）。
- 状态：已拍板口径；实现分 PR 进行（迁移 PR-1、导入与回填 PR-2、接口 PR-3b、前端 PR-4b）。

## 背景

甲方要看今天有多少销售单、多少钱，并追踪大单（哪些单大、金额、客户）。不另做“大单库存检查”页，也不判断库存能否支撑。现有老板看板的“按营收排序”只统计备件销售（6,977 张已生效单营收为空），排不出其他业务类型的大单。

## 决定

1. **新建「销售分析」页**，挂在销售单模块下；仅管理员、老板可见（独立页面权限键，实现时命名，暂名 `page_sales_analysis`，角色模板仅 `boss` 开，admin 恒放行）。只展示数据。
2. **销售单金额三项并存**：不含税金额（`amount_ex_tax`）、含税订单金额（原列「订单金额」，新增列）、营收（现有利润口径）。用一个多选控件选择显示其中一项或多项并排；可按任一已显示金额倒序排列。
3. **含税订单金额**：`f_sales_order` 新增可空列 `amount_inc_tax`、`is_tax_inclusive`、`tax_amount`；导入写入；从历史原件回填（与 D-40 回填同一作业，生产执行只在门控发布中进行）。没有值显示为空，不用推算值冒充。
4. **销售单类型 = 业务类型**（`f_sales_order.business_type`，原列「业务类型#」，当前 14 个值），多选筛选。
5. **日期预设**同 D-39：全部、一年、半年、30 天、15 天、7 天、今天、昨天、前天，外加自定义；默认今天。
6. 页面可显示已对账字段，口径与权限按 D-40。

## 影响与验证

- 不修改老板看板现有订单列表与 `REVENUE_BUSINESS_TYPES` 口径。
- 验收：按各金额倒序前 20 单与只读 SQL 一致；类型筛选计数与生产分布一致；权限矩阵 admin/boss 可见，其他角色 403。
