# D-39 独立项目备注

- 日期：2026-10-15。
- 来源：杨金臣 2026-10-15 16:58Z 裁定（需求00009）：为维保项目新增独立 `project_note`，与 D-32 的 `no_return_note` 并存。
- 状态：已确认；实现见 PR #382，迁移 `a40c9e1d7b52`。

## 背景

D-32 的免返标注只作免返提醒，`01_项目概览` 中只读。项目还需要一个与免返无关的通用人工备注，并能在签名工作簿里维护。

## 决定

1. **独立字段。** `maintenance_project.project_note`（TEXT NULL，最多 500 个 Unicode 字符，原串计数，不截断）。与 `no_return_note`（2000 字符，D-32）分开保存、显示和审计，互不覆盖；只作人工标记，不参与免返、领用、返还、收货、成本或任何计算。
2. **网页与签名 01 双入口。** 概览基础信息可编辑；signed `01_项目概览` 增加可编辑“项目备注”单元格，回传写同一字段。只开放这一个新增字段的 Excel 回写；D-32 的免返标注在 01 中仍只读，其他概览字段回写不在本条范围。V2 开关关闭时 Excel 不能写此字段（旧 V1 上传 422），只能网页维护。
3. **沿现有主档契约。** 复用实名、主档管理权限与项目范围、项目级 version CAS、审计及工作簿 revision。CAS 是项目级的：他人修改同一项目的其他主档字段后，旧快照提交备注同样得到 `stale_project_note` 409。
4. **文本合法性。** 空白或 null 为清空；超长、公式（Excel）拒绝。含 Excel/XML 1.0 不可表示的控制字符（`[\x00-\x08\x0b\x0c\x0e-\x1f\ufffe\uffff]`，制表、换行、回车除外）（含 Excel 保存的 `_xHHHH_` 转义形式）时，API 与 Excel 上传均拒绝（422）；项目主档其他文本字段（名称、销售等）在服务层同样拒绝。导出对所有单元格兜底剔除这些字符，历史脏数据不再导致整本导出 500。
5. **项目列表导出可选此列**，默认列不变。

## 影响

- 新增加法迁移；常规回退保留列与数据，非空时 downgrade 被拒。
- 不改变 D-32 任何口径。

## 取代关系

补充 D-32，不取代。
