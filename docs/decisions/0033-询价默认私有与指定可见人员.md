# D-0053 询价默认私有与指定可见人员

- 日期为 2026-11-02，按用户本轮明确补充执行。
- 本决定覆盖 D-0052 中询价及其关联报价对全部售前用户公开的范围规则。
- 用户确认采购或报价人可看全部已提交询价。未提交草稿仍仅本人和管理员可见。

## 范围

1. 售前菜单仍是进入功能的前提。已提交询价默认由发起人、具备报价权限的采购或报价人、管理员查看。其他人须由发起人或管理员显式指定。
2. 管理员采用系统的 admin、boss 角色。采购或报价人采用现有 action_presales_quote 有效权限，支持管理员配置的权限覆盖。仅有售前主管动作权限不额外扩大本条可见范围。
3. 发起人和管理员可以增加或撤销指定人员。空选择表示没有额外查看者，仍保留采购或报价人和管理员的固有访问权。收件人须为有效账号，查看时仍须具有售前菜单权限。
4. 草稿与从未提交即删除的草稿仅本人和管理员可见，额外指定人员和采购须等提交后查看。已提交后关闭或撤回修改的单据仍按相同记录权限判定。
5. 报价、历史、查询提示、统计、工作簿和回执须服从相关询价的现时权限，不能通过指定 ID、其他人的旧 Excel 或历史修订绕过。撤销授权立即生效。已有独立主动报价保留其原有流程；不得借其关联字段泄露无权访问的询价。
6. 客户名仍受 data_customer 控制。额外可见授权不自动给予整单维护、管理员或主数据权限。

## 兼容

复用现有整单受众规则。新单默认私有，非空指定人员保存为 include。历史明确的 include 人员及其已有分组仍视为已有额外授权；旧 public、空规则和 exclude 不形成对其他销售的隐式全员授权。维护新授权时只提供具体人员选择，已有分组成员可在加载授权时显式展开为人员，确认保存后使用当时所选人员。

授权变化加锁并核对单头版本，使用新的不可变受众规则记录，不修改历史报价或成交快照。读取历史时仍先核当前询价权限。

旧报价 Excel 若未保存完整的价格来源授权范围，不能用当前已替换的价格猜测旧文件来源。此类文件提示重新下载，再进行预览或确认。新导出文件记录所有实际引用来源，已有预览和应用回执同样检查现时权限。
