# D-0064 维保 Beta 接口弃用范围

2026-11-18，杨金臣确认先在代码中标记生产前端未使用的 82 个维保 Beta 接口，后续关停用 GitHub issue 跟踪。核对基线为生产发布 `ccefa17c`，本次标记基于 main `3cbb72a4`。

## 范围

- 按 HTTP 方法和路径逐项划分。97 个受 `require_maintenance_beta` 保护的操作中，82 个标为 `deprecated`，15 个标为 `retained`。完整范围见[维保 Beta 接口清单](../api-contract/maintenance-beta-routes.tsv)。
- `deprecated` 表示退出新功能排期，OpenAPI 对应操作声明 `deprecated: true`。此阶段原客户端仍按既有地址、权限和请求协议调用。
- `retained` 的 15 个操作服务于项目面板：验收报告 5 个、负责人映射 2 个、回款登记与修改 2 个、项目采购明细 1 个、现场领用 5 个。

## 后续关停

按业务模块实施关停。旧发布探针、签名工作簿回放或其他调用方如涉及被标记路由，在该模块关停时交接。清单以 HTTP 操作为单位，共用服务、历史事实、附件和审计记录分别按其业务归属维护。
