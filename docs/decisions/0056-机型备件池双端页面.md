# D-0076 机型备件池双端页面

2026-11-26。业务方确认机型备件池按整机型号建清单，逐项或批量核对 PN，并要求 itsp 与 Shop 都提供同一页面。[需求 #561](https://github.com/Jinchen-Yang/it-spareparts/issues/561) · [双端接入与验收](../integrations/model-parts-v1.md)

- 两端入口均为「机型备件池」。在机型中查询备件，在备件详情反查所有已确认的机型。一个 PN 可归属多个机型，按同一份库存显示。
- itsp 维护机型、机型与备件的归属及其依据，备件使用已有的稳定 part_id。Shop 提供实收 PN 的好坏件在手数量。未关联或读取失败的库存显示未知。互通 PN 池继续表达可替代料号。
- 两端沿用各自的登录。目录查看与维护分别校验，Shop 登录身份不自动获得 itsp 维护权限。正式跨端授权方式需依据业务方确认。
- 两端验收用不同浏览器。先在有权的维护入口加入一个 PN，再在另一系统查机型、PN、部位和依据，核对同一库存，再移出这条归属。
