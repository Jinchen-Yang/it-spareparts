# D-0068 询价报价池：报价备注上移行内、描述可点编辑、不报与关单入口退场

- 日期：2026-11-18。
- 编号：D-0068。文件 `docs/decisions/0048-询报价备注列描述编辑与不报关单退场.md`。
- 来源：宋丽芳 2026-11-18 前后微信反馈（金臣转交，批注见[需求 00015](../requirements/需求00015.md)中的转引）：
  「询报价那里能不能把描述改成可以点击的」「此外 能否增加个备注的地方」；
  截图批注：「在单价后面需要增加一列备注项 很多通用的报价要进行及时的标注 还有一些
  其他的情况 比如此单的控制器报价为无内存的控制也需要及时告知……」「这两个按钮可以
  直接省略 我们不存在不报的情况 及时找不到的货物和不想做的单子报价可以为0 另外
  目前来看关单按钮没有诉求」。
- 状态：已确认，候选待验收。

## 决定

1. **报价备注上移为行内列。** 询价报价池（`/presales/pool`）在「单价」列之后、
   「税」列之前新增「报价备注」列，直接编辑，随本行「保存」生效；字段沿用报价
   `notes`（报价备注），不新增数据列、无迁移。展开行原「报价备注」输入移除
   （避免双入口）；「询价备注」（询价行 `notes`，失焦保存）保留在展开行不变。
   备注定位：报价员对通用报价与特殊情况（例：控制器报价为无内存配置）的及时标注。
2. **备注随答复可见（告知链路）。** 销售侧「当前答复」展示（询价单列表/详情
   `answerSentence`/`CurrentAnswer`）与池页「复制」转述给客户的句子在有报价备注时
   附带备注。Excel 报价表已有「采购备注」列（`quote_workbook`），不改。
3. **描述可点击：查看全文并可编辑。** 池行「PN / 描述」列描述点击后弹出编辑框
   （展示全文，确定保存）。编辑走共享池行内修改（D-0052 第 4 条白名单新增
   `description`）：具备售前权限、能看到该询价的账号可编辑未关单行（D-0053）；**只改描述不作废当前报价**
   （与备注同类，不进价格条件白名单）；行版本与并发冲突语义照旧，`line.edited`
   历史记录变更字段「描述」。询价单详情页比价表的描述点击打开行详情抽屉（只读）。
   描述可显式清空（改错粘贴的场景）。
4. **「不报」入口退场。** 移除池页「不报」按钮与「填写报价」工作台
   （ProcessPage/QuoteGrid）的「不报」选项及原因输入。无货或不想做的行按业务口径
   **报价 0**（`set_price` 允许 0）。历史 `skip` 数据不清理：池页「不报」筛选
   tab 与各处「不报：原因」只读展示保留；`skip` 后端接口保留以兼容回退与历史
   读取，前端不再提供新增入口。已 `skip` 的行可直接重新报价恢复（现有
   `set_price` 覆盖语义）。
   **Supersede**：D-0052 第 5 条「可按……不报筛选」的 tab 保留但仅作历史查看；
   D-0052 验证项「单页完成……不报」不再作为新增能力；「报价必须为正」类推论不成立。
5. **「关单」入口退场。** 移除池页行内「关单」按钮与询价单详情页「成交关单/
   未成交关单」按钮及配套弹窗、成交报价选择流程。后端 `closeInquiry` 接口与
   关单数据（状态、结果、成交快照）保留：历史已关单单据照常展示、可回退。
   本决定不删除任何存量数据，不承诺未来不再恢复关单入口（业务方现无诉求）。

## 边界与不变

- 不改 Excel 询价/报价导入导出链路；报价表「采购备注」列继续可用。
- 询价行条件白名单（数量/坏件返回/PN 一致）触发作废答复的语义不变；描述、
  备注、期望交期只改不重置。
- 报价 0 转述（`¥0.00`）如何使用由业务自理，系统不拦截。
- 主动报价（proactive）路径的界面文案如提及「不报」仅作历史状态展示。

## 验证

- 后端契约：`PATCH /presales/pool/lines/{id}` 改描述成功、清空成功、保留当前报价、
  行版本冲突照旧；改条件触发作废的既有用例不回归。
- 前端：`tsc`/`vitest`/`vite build` 通过；池页备注列、描述编辑、无「不报/关单」
  按钮的用例更新；历史 skip 展示用例保留。
- 开发验证不替代用户点按验收；本决定不授权生产部署。
