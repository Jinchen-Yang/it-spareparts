# D-0074 网页导入库存分析仓单

2026-11-23，用户确认在「数据导入」补充网页仓单入口。一份氚云工作簿可含「入库单」「返库单」「直采直退」中的一个或多个业务页签。每页保留原单据类型。「重点保留」和隐藏选项页按已有契约跳过。全仓实际出库仍以 D-0066 的 CKD 为准。

- 提交仓单使用在用实名账号已有的 `page_import` 权限，作业及批次回执沿用数据导入的历史查询。库存管理分析的读取权限沿用 D-0072。
- 用户选定完整工作簿后提交，以后台作业校验全部页签及数据。成功时在同一事务更新库存分析投影并留下作业回执，逐页显示单据及明细数。非法页签、无仓单、旧版本或同时间内容冲突使整本失败。
- 更新沿用来源 ID、修改时间和完整明细的规则。同一内容复核为未变更。本次没有提交的历史单据继续保留。既有采购、销售、库存和维保的导入流程分别运行。

2026-11-25，用户提供氚云原件并确认适配导入和展示。仓单工作簿增加 CKD 页签「发货单号」和「出库_发货单」，入库单兼容「入库单号」。同一来源在每本工作簿只能出现一次，回执显示实际页签名称。

CKD 的单据与备件明细分别以源数据 ID 识别，按出库日期分析，以数据状态「已生效」统计业务量。出库作业人取单头拣货人员并显示为出库拣货岗位。单头出库仓与备件所在仓分别保留。备件按出库数量及原单位分析，整机按单头整机出库数及原单位单列。按仓展示原件中已导入的业务日，日期从未出现的时段显示未覆盖。实际出库的来源依据见 D-0066。
