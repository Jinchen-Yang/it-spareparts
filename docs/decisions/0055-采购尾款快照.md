# D-0075 采购尾款快照

2026-11-23，用户确认采购分析「排行」筛选摘要用「已付尾款」「待付尾款」替换「成交供应商」。

- 两个指标分别取氚云采购单头同名源列，按采购日期与当前订单范围统计已生效单，每单一次。三种采购金额口径沿用 D-39。
- PN、商品分类、池、单位等明细口径隐藏两张卡。金额及其缺值数随 `data_purchase_cost` 权限遮蔽。
- 每列分别保留当前快照，按成功处理的导入批次号覆盖，沿用销售待收款 D-0069 的更新规则。带列但单元格为空记未知，旧模板缺整列时保留已有值。显式零和负数按原值保留。按 D-0050 校验源值，非空无法解析或同单跨行冲突时拒绝该单。
- 有已知值时合计已知金额并注明缺值单数，无已知值时显示「—」。迁移保留历史未知。历史原件回填另行安排。
