## 实施口径

### 端点与权限（R33 第 2 条）

- 路由前缀 `/api/maintenance/analytics/maintenance-dashboard/`：`options` / `summary` / `projects` / `parts` / `valuation` / `receipts` / `quantity-checks` / `export`，全部 `Cache-Control: no-store`。
- 数量端点（除 valuation 外全部）：登录（401）+ `page_maintenance`（403）+ 项目范围。项目范围 = `maintenance_scope_project_ids`：`None` 全量、空集拒绝（不是全量）；用户显式选择与授权范围取交集，手填越权项目 ID 看不到数据；范围收敛先于聚合/估价/TopN/分页/导出。
- 估价端点 `valuation` 额外挂利润门 `_require_profit_visibility`（admin 或 `data_profit`；readonly 兜底模板有 `data_profit` 但无 `page_maintenance`，仅利润键不放行）。
- **无金额权时数量端点响应不含任何金额字段（键不存在，不是 null/0）**；导出不含金额列与估价元数据（列头都没有）；金额排序 `bad_value_desc` 一律 422（`sort_requires_profit_permission`），不静默降级；`options` 的排序候选已按权限剔除金额键。
- 审计日志只记布尔标志（amounts/keyword/scoped/kind），不落关键词与项目 ID 自由文本。

### 时间口径（R33 第 6 条）

- 预设 `7d/15d/30d/half_year/year/all/custom`；默认近 7 天含今天（上海日历日 `today−6 ~ today`）；custom 必须双日期、起止不得倒置，否则 422。
- 半年/一年按日历月回推（月末日 12-31 → 06-30）；期间边界为上海时区当日零点，半开区间 `[start 00:00, end+1 00:00)`。
- 非法日期/ID/排序/分页参数一律 422 不 500。

### 数量口径

- **返件实收**：`maintenance_rkd_return_line.line_status=active`，按上海业务日入期；退货 `f_maintenance_line.return_qty` 是另一事实，分开计算、永不冲减或相加。
- **好件领用（实际领用量）**：现场领用 `status_mapping_state=mapped` 且 `normalized_status ∈ {confirmed, corrected}`、行 `is_active=true`，按 `issue_date`；界面注明「实际领用量（未采集件况）」（R33 第 5 条）。
- **免返/待判定**：复用 `line_details` 只读，免返领用量单列一列，不冲减任何量（R33 第 3 条）；不剔除硬盘不返项目。
- 未关联需求单实收、无业务日实收各自单列（提示条/独立列），无业务日实收不计入期间。
- **同期返还率**（R33 第 4 条）= 同期返件实收 ÷ 同期实际领用；分母 ≤0 → 无率（null + 原因，不是 0%）；领用 >0 且实收 =0 → 0%；>100% 原样展示；不扣免返；D-14 历史官方率不在本看板发布。

### 估价口径（R33 第 1、7 条）

- 行级 `V = qty × 选用参考价 × 折算系数`，行内 HALF_UP 两位后求和；双税（含/不含）分别计算。
- 系数政策为代码内版本化模块 `app/services/maintenance_dashboard_valuation_policy.py`：`POLICY_VERSION="mdv-2026-10-21-r33"`，坏件/坏品/故障 0.20、废品 0.05、成品 1.00，件况未知不估；响应与导出携带政策版本；页面一切金额处标注「估算」与「PN 交易参考×假设折算；非变卖收入」。
- 参考价复用 `resale_price_reference`/`purchase_analytics` 既有算法做看板内部批量估价（Q10），**不改商城目录接口**（`/integrations/resale/...`，D-42/D-43 契约零行为变化，回归测试锁定）；采购参考优先、销售回退（`chosen_reason=purchase_fallback`）；30 天窗口、7 天半衰、数量加权、`qty>0`、单价 >0、排除已确认源错误；单头批次行遵循 D-39；**锚点 = 统计结束日**，未来成交不入样本。
- 单位校验：样本单位 vs `dim_part.unit`；主数据缺单位/样本缺单位/样本混单位/单位不一致 → 该域不可用（reason `unit_missing_master`/`unit_missing_sample`/`unit_mixed_samples`/`unit_mismatch`）；双域均不可用 → 待估（不计 0）；不做盒/件换算。
- 坏件口径：`RKD_RETURN_TEST_RESULTS`（坏品/坏件/故障/废品）计入坏件，**废品计入坏件实收与估价**；件况未知不计入坏件实收（M02），其行状态为待估（`unknown_condition`）但待估坏件量不含它；`待估` 永不计为 0 元。
- **覆盖率 = 已估坏件数量 ÷ 坏件实收数量**；M02=0 时无覆盖率（null）。
- PN 身份归并：`part_id` → 去空白规范 PN → 原始文本兜底；无法归一（`pn_unresolved`）待估。

### T4 需求单数量核对（R33 第 7 条）

- 复用 `summarize_demand_returns`（批量 ≤500）；不提供历史截止日参数（该服务拒绝 `as_of`）。
- 逐单 `差额 = max(N−R, 0)`、`超收 = max(R−N, 0)`，`当前累计`（整单跨全部 PN/来源/件况）；**不发布「欠返/逾期/已返」等返还状态**；免返不从 N/R 剔除（D-31/D-32）。
- 未关联需求单实收按项目汇总，仅全范围视角（受限范围账号不显示，避免以局部推断全局）。

### 导出

- `export?kind=projects|parts|receipts|quantity_checks&format=csv|xlsx`，完整筛选集（不带排序参数，服务端默认序）；行数上限 50,000（413）。
- CSV 撇号只加公式形态单元格（`_safe_formula_only`）：`=1+1` 前缀转义，`-5`、以 `-` 开头的 PN 不误伤；无回溯正则。
- XLSX 数值写数值单元格（xlsxwriter constant_memory），文本显式 `write_string`，超 32,767 字符 413。
- 无金额权导出不含任何金额列/估价元数据/政策版本列。

### 前端

- 新页 `/maintenance/dashboard`（导航「维保项目 → 数据看板」，`page_maintenance`），四页签：T1 回收与领用总览 / T2 项目对比 / T3 PN 排名与估价 / T4 需求单核对。
- URL 即筛选状态（`hooks/useUrlState.ts`）：`tab/range/from/to/project/business_type/q/sort/page/ps`；默认值不入 URL；默认近 7 天含今天。
- `amounts_visible` 以 `/options` 服务端事实为准（不用本地权限快照猜测）；无金额权时金额卡/列/政策说明**整块不渲染**（非 CSS 隐藏、非 ¥0）；T3 无权走 `/parts` 数量端点，有权走 `/valuation`。
- 颜色仅用现有主题 token（`CHART_COLORS` / `tokens.ts` / `var(--mb-*)`），colorGuard 无新增 hex。
