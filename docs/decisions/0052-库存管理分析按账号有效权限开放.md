# D-0072 库存管理分析按账号有效权限开放

2026-11-20 用户确认。「账号与权限中心」中的“库存管理分析”控制全仓仓单分析的读取。老板、管理员职位默认勾选，其他职位默认关闭。管理员可使用原有账号个别调整或可编辑的职位模板向普通账号授权，也可取消具名管理员的勾选。系统内置 admin 账号和锁定的管理员模板沿用原有编辑保护。

菜单、直达路由、来源覆盖、矩阵、排行、整机、测试、单据及明细统一使用实名账号的 `page_inventory_analytics` 有效位。账号模板快照与个别调整决定生效值。职位模板保存、同步和会话撤销沿用权限中心现有语义；权限变更后旧会话须重新认证。默认勾选值在模板、建号和存量迁移时写入。实名权限图缺少该位时关闭入口。共享口令登录不具有实名授予。

现有 `own_customers_only` 用于客户成交明细与相关公司级经营读面，D-0055 的角色和客户限制具体指向销售、采购接口。库存分析只读取仓单与货品投影，提供仓库、作业人、业务单号、PN、单位和数量，没有结构化的客户归属、客户名单或成交金额字段。业务单号和描述显示来源原文。本次依据仓单分析的账号授权提供这些字段。涉及客户或价格的其他接口继续执行各自的数据权限；后续引入这些数据时须另外核对可见范围。实际出库来源沿用 D-0066。
