# D-0063 离职销售：账号删除联动单据隐藏（可恢复）

- 日期：2026-11-17。
- 编号：D-0063。文件 `docs/decisions/0043-离职销售账号删除与单据隐藏.md`。
  前一号为 D-0062（`0042-下载表格账号附显示姓名.md`）。
- 来源：金臣 2026-11-17 口头需求（R19 落地机制）：「离职销售在管理页面账号页面
  可以删除账号，然后可以选对应的单据销售单采购单隐藏不显示，然后能恢复显示等」；
  同日拍板三个口径（见决定 4–6）。
- 状态：代码随本决策 PR 合入 main；未上线，生产以 `release-` 标签为准。

## 决定

1. **离职事实源 = 管理员删除账号动作**。删除沿用既有软删（`sys_user.deleted_at`，
   2026-08 `83068800`），不真删、历史引用保留。本决定新增：删除时**可选勾选**
   「同时隐藏其名下销售单」；勾选即置 `sys_user.hide_documents=true` 并审计。
   **Supersede**：D-0056 §1「未获权威离职名单前不隐藏」与本决策冲突部分废止——
   权威信号即管理员删除动作；#136 C2（角色×可见性矩阵）不再阻塞本项。
   2026-11-11 业务答复「账号停用不隐藏单据」中「停用」语义维持不变（停用 ≠ 删除）。
2. **隐藏是显示口径，不改事实**：被隐藏销售的单据**仍参与全部汇总重算**
   （营收/毛利/KPI/趋势/成本移动加权/库存推导一律不动）；仅在指定展示面过滤
   （见 4）。隐藏与恢复均**可逆**，不做任何物理改动，`data_status` 不变。
3. **姓名对齐按精确匹配**：隐藏集合 =「已删除且 `hide_documents=true` 的账号的
   `salesperson_name`」。删除弹窗展示预览（名下已生效销售单 N 张、关联采购单
   M 张）供管理员核对映射；账号未配「对应销售名」时不可勾选隐藏（提示先补配）。
   只出现在旧单据、无账号的人名不在本机制覆盖内（维持 D-0056 §1 事实说明）。
4. **生效范围（拍板：仅两页含导出）**：
   - **销售分析**：订单列表与导出隐藏其销售单；人员筛选候选、按销售分组/排名
     剔除该人；汇总 KPI、趋势、直方图照算。
   - **采购分析**：订单列表与导出隐藏**关联销售单被隐藏**的采购单（拍板：跟随
     关联销售单，不按 purchaser）；关联销售单号筛选候选剔除该人；采购员维度、
     汇总照算。
   - **不在范围**：老板首页看板、销售看板、维保看板/项目、数据治理、老板经营
     看板导出——维持现状。两页在存在隐藏人员时展示提示条「已隐藏离职销售 N 人
     （不影响汇总金额）」。
5. **恢复**：恢复账号（undelete，本决策新增入口）默认同时恢复单据显示
   （`hide_documents=false`）；已删除账号可在管理页独立切换单据显示/隐藏。
   恢复账号仅清除 `deleted_at`，不自动改 `is_active`（启用另行操作）。
6. **权限**：删除/恢复/隐藏切换沿用账号管理写权限门（`action_account_manage`，
   仅管理员）；预览与已删除列表同门。审计事件：`account_delete`（扩展 payload
   记 hide_documents）、`account_restore`、`account_documents_visibility`。

## 边界与不做

- 不改 `f_sales_order` / `f_purchase_order` 任何数据（无新列、无标志位写入）；
  隐藏集合完全由 `sys_user` 派生，避免触碰「不自动改写历史事实」硬边界。
- 不隐藏维保单/维保项目销售；不做按采购员隐藏；不做部分单据勾选（粒度=整个人）。
- AI 智能体平台不变量不受影响（本机制为人工管理动作，非 AI 写业务状态）。
