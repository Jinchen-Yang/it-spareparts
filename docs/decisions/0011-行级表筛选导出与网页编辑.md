# D-33 行级表筛选导出与网页编辑

- 日期：2026-10-15。
- 来源：杨金臣对需求00006的明确答复及需求00004 R4；依据 `R/01-开工计划.md`、P2 边界、需求00004/00006调研和 `R/金臣答复-2026-10-15.md` 第17节（R 为本批调研目录）。
- 状态：已确认；本条归档范围和契约，工作台及导出调整尚待实现和验收。

## 背景

现有全项目行级表偏重下载补价，网页可编辑字段少于工作簿。杨金臣确认：“下载可全字段多字段范围筛选，然后所有表内可编辑字段在网页中应同样可以直接编辑而不用下载后再编辑再上传。”该答复取代 Q26～Q28 的旧候选范围。

## 决定

1. **行级表支持全字段、多字段、范围筛选并导出完整筛选集。** 范围是全局行级表、项目总表 03 和既有网页业务列的并集，包含事实字段及各自可见的系统／有效／人工成本；技术身份、哈希和签名不是任意查询列。按字段类型注册文本、枚举、数值、日期及空值运算；多字段组合，网页、count 和导出共用服务端权限、有效性与筛选语义，不只筛当前页，不静默截断。
2. **表内所有可编辑字段在网页同样可直接编辑。** 包含 PN、描述、需求量、SN、退货量、备注、人工未税单位成本及原因；新增／作废作为受控动作。单头、系统成本及派生结果仍按既有只读语义；“全字段”不授予任意数据库写权限。领用与返还件页内维护另见 [D-31](0009-返还数量上限与需求单核对.md)。
3. **复用既有编辑、审计和乐观锁链。** 页面与 Excel 共用事务内事实／人工价命令，校验实名、项目范围、事实 digest、价格基线和版本；PN 与稳定 part_id 同步，旧人工价按既有规则失效。只提交实际变更和明确清空，同一行事实与人工价同事务成功或回滚，保留前后值、原因及操作者。原样回传不制造人工保护；字段保护按 [D-34](0012-原件字段保护与终态确认.md)。
4. **同字段网页与 Excel 同权。** 沿用既有项目、动作、利润／成本及项目总表金额资格，不为工作台新增角色或扩大范围。无权金额、衍生排序、条件、计数及明文价格令牌均不可泄露；混合项目金额条件必须先明确限定到有权项目，不能暗中丢弃无权行后宣称全集。
5. **全部 WBDD 明细导出默认升序（00004 R4）。** 统一为 `order_date ASC NULLS LAST → order_no ASC NULLS LAST → order.id ASC → line_no ASC NULLS LAST → line.id ASC`，保证同一单头连续及稳定尾键。覆盖项目总表 V1/V2 的 03／单页、全项目行级表、明细 CSV、逐单 XLSX、V3 的 03、合同工作簿／ZIP及往返模板中的 WBDD 明细。已升序出口也核对完整键，不漏保留在线的旧出口。
6. **排序只改变明细输出次序。** 网页列表默认顺序、排名、归档原件、错误回执、ZIP 成员及费用／回款／收货各自既有排序继续保留；不替换各出口原有查询集合、筛选或权限。工作簿身份、签名基线、删行作废与幂等重放不按 Excel 行位定位，新旧行序文件均须兼容。

## 影响

- 同源查询须先在数据库筛选再分页或迭代导出；系统原始成本、有效成本和人工证据分别命名，不借统一筛选改变旧 V2 系统列含义。
- 旧 12 列补价文件与项目往返协议继续兼容，普通核对导出明确其可回传能力。页面批量仍逐行编排；Excel 保留原整份事务及既有并发协议。
- 本次不新增迁移、依赖或框架，不开启 cutover，不实施整体重构。后续须有各字段网页／原件往返、权限、真实并发及全部导出集合／顺序契约证据。

## 取代关系

新增行级工作台范围，并以需求00004 R4 修订上述 WBDD 明细导出的历史倒序约定；不取代 D-01/D-02 的项目工作簿身份、作废和并发口径，不把已有实现与 D-02 的文字差异默认为新授权。D-03 既有金额资格及其他领域权限继续有效。
