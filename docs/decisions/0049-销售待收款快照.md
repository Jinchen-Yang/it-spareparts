# D-0069 销售待收款快照

2026-11-19，用户确认销售分析采用氚云销售订单头的「待收尾款」。

- 每单保留当前快照。成功处理且带「待收尾款」列的销售订单上传按导入批次号覆盖，源修改时间不参与排序。空单元格记录未知，缺整列的旧模板不覆盖已有快照。
- 待收尾款按 D-0050 校验。非空值无法解析或同一订单跨行金额冲突时，拒绝该订单并保留既有快照，其他合法订单继续处理。
- 历史回填回放已归档销售原件，采用同一批次规则。旧批次与同批次重放不会覆盖已记录快照。
- 订单明细按商品显示氚云原单价，每单显示一次待收款。汇总按当前筛选的订单计算一次，未知单数单列提示。待收款遵循现有对账金额权限。
