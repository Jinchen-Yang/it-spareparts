# 库存管理分析候选验收

入口为「库存管理 → 库存管理分析」或 `/inventory/analytics`。在「账号与权限中心」为实名账号勾选“库存管理分析”后可读全仓作业。老板和管理员的默认模板勾选此项。具名管理员取消勾选也会失去访问。职位模板保存和同步各按现有流程操作。访问范围详见 [D-0072](../decisions/0052-库存管理分析按账号有效权限开放.md)。

## 验收准备

在独立副本先把数据库迁移到当前代码的 Alembic head，前后端使用同一提交。新表为 `warehouse_analytics_document` 与 `warehouse_analytics_line`，新权限为 `page_inventory_analytics`。首轮接入及增量步骤见[来源接入](../plans/inventory-analytics/来源接入.md)。导入结果按文件记录，保留原始导出的受控副本以便复算。当前数据更新通过离线命令执行。

## 点按核对

1. 使用获准账号打开页面，检查默认最近 30 天、各来源首末业务日、未接来源显示。没有 CKD 时实际出库显示“待接入”。分别在账号矩阵和职位模板授权、同步或撤销。用普通账号和具名管理员验证登录、菜单、直接链接和所有读接口，保留旧会话检查撤销后的请求。系统内置 admin 账号沿用全局编辑保护。使用升级前留存的登录会话重开库存深链，核对菜单与服务端确认的勾选一致。
2. 选择有业务的日期，核对日、周以及单据数、明细行数、不同 PN 数。悬停柱和折线点，核对所属日期、指标和匹配货品。切单一明细单位后再核对数量。
3. 人员榜分别查看仓库拣货和直退经办，取同名跨岗位人员核对。退货 PN 榜先查销售退货集中度，再看某个型号的周分布。整机按单头及其原单位核数。
4. 从交叉格进入单据，再展开单内货品。用同单多行、多中心、空字段以及跨周样本检查匹配行和数量。返回上一层后核对筛选、页码与指标。刷新后重复查询，观察是否看到已提交的新版本。

## 发布与回退

候选评审和使用方点按验收分别登记。生产操作另行授权，并遵循仓库发布规则。各并行功能合入后检查迁移链单头，确认备份可读，先迁移再启动同版本的前后端，记录精确 SHA 与发布标签。

需要回退页面时切回先前的前后端版本，并停用新导入命令。若还需回退数据库，先备份两张分析表与权限配置并核对后续迁移依赖，再在维护窗口按本版本前序修订执行降级。降级删除分析投影及权限键，恢复时须重新迁移并导入保留的完整仓单。
