# 库存管理分析候选验收

入口为「库存管理 → 库存管理分析」或 `/inventory/analytics`。在「账号与权限中心」为实名账号勾选“库存管理分析”后可读全仓作业。老板和管理员的默认模板勾选此项。具名管理员取消勾选也会失去访问。职位模板保存和同步各按现有流程操作。访问范围详见 [D-0072](../decisions/0052-库存管理分析按账号有效权限开放.md)。

## 验收准备

在独立副本先把数据库迁移到当前代码的 Alembic head，前后端使用同一提交。分析表为 `warehouse_analytics_document` 与 `warehouse_analytics_line`。首轮接入及增量步骤见[来源接入](../plans/inventory-analytics/来源接入.md)。数据更新可用离线命令，或由有「数据导入」权限的实名账号从网页提交。保留原始导出的受控副本以便复算。

## 点按核对

1. 使用获准账号打开页面，检查默认最近 30 天、各来源首末业务日、未接来源显示。没有 CKD 时实际出库显示“待接入”。分别在账号矩阵和职位模板授权、同步或撤销。用普通账号和具名管理员验证登录、菜单、直接链接和所有读接口，保留旧会话检查撤销后的请求。系统内置 admin 账号沿用全局编辑保护。使用升级前留存的登录会话重开库存深链，核对菜单与服务端确认的勾选一致。
2. 选择有业务的日期，核对日、周以及单据数、明细行数、不同 PN 数。悬停柱和折线点，核对所属日期、指标和匹配货品。切单一明细单位后再核对数量。
3. 人员榜分别查看仓库拣货、直退经办和出库拣货，取同名跨岗位人员核对。退货 PN 榜先查销售退货集中度，再看某个型号的周分布。整机按单头及其原单位核数。
4. 从交叉格进入单据，再展开单内货品。用同单多行、多中心、空字段以及跨周样本检查匹配行和数量。返回上一层后核对筛选、页码与指标。刷新后重复查询，观察是否看到已提交的新版本。
5. 在「数据导入 → 仓单工作簿导入」上传分别包含入库、返库、直采直退和实际出库页签的完整工作簿。核对作业各页签单据及明细统计和批次回执。重传时核对未变更单据数，加入未支持页签时核对整本失败。只持有库存管理分析查看权的账号无法提交。

6. 在收发总览选择「实际出库（CKD）」。核对日和周单量、出库拣货前五和「各出库仓的已导入业务日」，从仓库下钻到单头出库仓及明细所在仓和库位。选一个无出库来源记录的日期查看趋势缺口，再按单一单位核对备件数量。整机出库数在单据和整机看板核对。

## 发布与回退

候选评审和使用方点按验收分别登记。生产操作另行授权，并遵循仓库发布规则。各并行功能合入后检查迁移链单头，确认备份可读，先迁移再启动同版本的前后端，记录精确 SHA 与发布标签。

需要回退时先停用 CKD 导入并切回先前的前后端版本。数据库可保留本次新增的可空列。若维护窗口内需要回退本次迁移，先备份分析表并检查后续迁移依赖。降级 `ab73d15c804e` 到 `f261fbad9e04` 会删除单头出库仓字段。恢复该字段时应重新迁移，在隔离副本从完整 CKD 源文件重建出库投影并对账，保留其他来源。
