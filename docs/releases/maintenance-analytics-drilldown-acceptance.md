# 维保多维排名交付与验收

决策：D-25。跟踪：[#351](https://github.com/Jinchen-Yang/it-spareparts/issues/351)。用户已更正本次目标为 main，test 留给远期实验。本候选从生产基线 `02bd8ed` 创建，仅移植分析功能提交。

## 用户入口

维保项目 → 数据分析 → 多维排名。可切换分栏钻取、Pareto 排列图、项目热力矩阵；旧 PN 明细与开支统计仍在相邻页签。

选择 PN → 查看各项目分布 → 点击项目 → 项目面板「分析定位」→「返回分析 · 保留筛选」。矩阵单元格直接定位相应项目与 PN。项目定位为当前分析筛选范围，原项目经营总览保持原定义。

正式功能通过现有登录与网络入口使用，不要求 Tailscale。原演示环境的私网访问与本功能依赖无关。

## 候选构建人工验收清单

- 在本次 main 候选构建中确认三种视图均可切换；选一个有多个项目使用的 PN，核对分布数量与项目定位。
- 切换本年、全部、自定义期间以及项目/来源筛选；翻排名页，图形 Top N 不随表格页码改变。
- 在热力图点击与当前选中 PN 不同的格子；项目显示点击的 PN，返回恢复原选择与所有筛选。刷新项目页、新标签打开返回链接也正常。
- 使用能看汇总但没有项目详情权限的账号，确认数值仍可见，分布和热力格禁用该项目跳转并说明原因；有详情权限的项目仍能正常进入。
- 切换成本、缺价、需求单数；全缺价显示未知，部分缺价明确标注，需求单数没有累计贡献线。
- 使用低权限真实账号核对：只看到授权项目；无成本权不能取得成本指标、金额排序与成本占比；无客户权不提供客户维度/筛选。
- 确认新读页面没有生成、修改、作废业务记录。

本地浏览器与构造账号测试已经完成；以上真实账号点按验收尚未进行。
