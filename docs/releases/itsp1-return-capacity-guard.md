## 候选点按验收

在候选测试环境使用合成需求单 N=10，不操作生产：

1. R=9 时，下拉显示“剩余可录 1”；录1成功，录2显示中文容量错误。
2. R=10/12 时，该单不进新增候选，但仍可从需求列表和返还台账查询，R/N及超额不截断。
3. 修改原关联收货时保留该单，允许备注、同量、减量和作废；增加超过排除自身后的容量拒绝。
4. 将未关联行补链到满额单、将A行改挂满额B，均拒绝且原记录/两单数量保持。
5. 批量录入选择同一需求单，整批数量预检；保存逐行返回结果，不自动取消关联。失败重试保留原幂等载荷。
6. 批量维护显示当前关联的剩余和本行最多可填；容量409原文可见，不冒充版本冲突。
7. 标准导入同批累计超额逐行报错并整批拒绝；同批先增后减但最终不超额可应用。预览后占用变化导致计划或容量校验改变时，拒绝并要求重新预览。
8. 原单失效/归属异常时，页面保留历史身份供无增量维护，增加或补/改关联拒绝；标准导入有效来源行保留既有归属不明 pending 边界及作废优先规则。
