# 售前共享池独立生产候选 v1.44.0

决策: [D-0052](../decisions/0032-售前询价报价共享池.md)

本发布分支的父提交为生产标签 `release-hotfix-presales-load-e2e335bc-20261101` 对应的 `e2e335bc72bf8cb95ce72ffae5e0e8e151b6da5c`。发布范围为售前共享池、报价 Excel、与该功能相关的权限和历史修订、菜单和用户手册。右上角更新日志在生产已有的 1.42.0 前插入 1.44.0。发布分支同时更新 `follow-redirects` 至 1.16.2 以及对应 SBOM，以通过生产依赖审计。

## 上线影响

- 已提交的询价和已发布的报价对有售前权限的用户共享，包括以前设为私密的成本价、供应商和备注。客户名按客户信息权限显示。未发布的草稿仍受保护。回滚不能收回用户已经看到的信息。
- 询价和报价合并为「询价报价」。新报价保存后逐行生效，不报须写原因。在页面勾选询价行会下载所在询价单的全部有效行。使用新版报价 Excel，上传后先预览、确认才生效。
- 迁移回填询价行当前答复、记录报价的更新人，并取消未完成的售前待办。已完成的待办保留。数据库从 `a3c5e7f9b2d4` 仅升级到 `e5a7c9d1f3b6`。

## 发布与回退

1. 核对发布提交的父提交、精确 SHA 的两项 CI 和发布范围。备份数据库、上传文件及运行配置，记录原有镜像、路由和版本，在隔离环境完成恢复演练。
2. 停写后核对源版本与汇总计数。用同一发布提交的镜像执行 `alembic upgrade head`、`alembic check`。核对唯一 head、原报价及修订数、答复状态和待办变化，再启动新应用并切换入口。
3. 切流后通过只读请求检查公开入口、售前列表、报价历史、客户权限和 1.44.0 弹窗资源。保留旧容器与备份，记录精确标签、镜像、备份和验证回执。
4. 回退须先停候选写入。按运行手册将 schema 降回 `a3c5e7f9b2d4`，迁移按 `D-0052|` 标志恢复其取消的待办并移除共享池专用列。报价和修订保留。降级会删除共享池专用的答复信息，应依受控回滚流程留存切换后的数据，再恢复旧服务并验证路由和数据库版本。

删除测试的逐项处置见[原有测试复核](../handoff/2026-11-02-presales-shared-pool-test-audit.md)。生产身份与结果以实际发布标签和操作回执为准。
