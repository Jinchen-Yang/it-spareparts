## 行为变化

「销售分析」页（`/sales/analytics`，页面键 `page_sales_analysis`，仍只给管理员和老板）扩为看板：

- **筛选栏**：客户（按规范名合并，输入即搜）/ 客户类型 / 销售人员 / 商品大类 / 品牌多选；
  金额区间双端拖动条（可输入、1k 步长、默认不限）、区间口径、含负金额单 / 含无金额单开关。
  选了商品大类或品牌即按明细行统计（不含税为 ÷1.13 名义值，页面标注）。
- **KPI 条**（常驻）：单数、三金额、毛利 / 毛利率 / 成本覆盖率、成交客户与新老客、销售人数，
  每卡附上月同期增减（区间长于一个月不提供）。
- **四个页签**：概览（迷你趋势 + 三个 Top 5）、分组排行（10 个维度，任意列升降序，Top N +
  其他，集中度，较上月，点组下钻）、趋势（日 / 周 / 月、上月虚线、星期分布、点柱下钻）、
  订单明细（默认页签；任意列升降序、毛利列、CSV 导出，抽屉新增明细行）。
- 所有状态落 URL；旧分享链接（含 `customer` / `salesperson` 模糊参数）继续生效。

不改：老板看板 `/dashboard/*`、`REVENUE_BUSINESS_TYPES`、利润计算链路、对账块（D-40）。
回款视角本轮不做（D-44 §6）。

## 验收清单（按 D-44 影响与验证）

1. 同一筛选下：KPI 合计 = 分组排行各组（含“其他”）合计 = 趋势各桶合计 = 订单明细合计。
2. 所选区间按客户 / 销售 / 业务类型的前 20 组与只读 SQL 一致（±0.01）；毛利合计与老板看板同区间 KPI 一致。
3. 任意列升序 / 降序翻页不丢行、不重行；空值恒在最后。
4. 金额拖动条：拖动、输入（自动取整到 1k）、拖回两端等于不限；两个开关生效。
5. 选商品大类后金额只计匹配明细行，不含税带「名义」标注；按大类分组时提示“一单可计入多组”。
6. 对比上月：「今天」「昨天」「7 天」「30 天」有对比，「半年」「一年」「全部」显示不提供。
7. 新客 / 老客人数与只读 SQL（规范名首单日期）一致。
8. 权限：admin / boss 可见；sales / purchaser / readonly 403；关 `data_purchase_cost` 时金额为「—」、
   金额排序退回、金额区间禁用；关 `data_customer` 时客户类属筛选与分组不可用；关 `data_profit` 时无毛利。
9. 导出 CSV 与当前列表同序同列；超过 10,000 单提示收窄。
