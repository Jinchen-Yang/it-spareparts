## 3. 现状事实（2026-10-15 只读代码调查）

### 3.1 入口与交互

- 维保主页（项目卡墙）页头右侧有「全项目备件行级表」下载/上传组件（按钮文案「下载全项目备件行级表」）——`frontend/src/pages/maintenance/MaintenanceHomePage.tsx:94-97`（注释）、`:288-296`（`WorkbookRoundTrip title="全项目备件行级表"`）；前端测试按此文案断言——`frontend/src/pages/maintenance/__tests__/MaintenanceHomePage.test.tsx:232`。
- 下载前要**先选时间段**：同一行有一个时间预设下拉（今天/昨天/本周/本月/自定义），**默认「本月」**，选「自定义」时还要再选日期区间——`MaintenanceHomePage.tsx:163`（`useState<RangePreset>("this_month")`）、`:272-286`；预设枚举——`frontend/src/api/maintenanceWorkbooks.ts:14-20`。
- **没有「全部 / 不限时间」选项**：后端只接受 today/yesterday/this_week/this_month/custom，自定义必须同时给 from 和 to——`backend/app/services/maintenance_project_master_workbook.py:105`（`_RANGE_PRESETS`）、`:443-461`（`resolve_range`）；API 默认 `range=this_month`——`backend/app/api/maintenance_project_master_workbook.py:228`。
- 只有维保主页这一个入口；「需求单与同步」页、数据分析页、项目面板都没有这个全局下载（项目面板下载的是本项目总表／单 sheet）——`MaintenanceHomePage.tsx:250-252`（「需求单与同步」只是跳转链接）。

### 3.2 导出范围与权限

- 范围＝当前账号**可见项目**中、`order_date` 落在所选时间段内、且**已归属项目**的有效需求明细；**未归属项目的需求单不进表**；**不跟随主页的期限/业务类型/状态/关键词筛选**（只传时间参数）——`maintenance_project_master_workbook.py:464-504`（`_assigned_lines`：inner join 归属、按 order_date 窗口过滤）、`:800-815`（`build_global_lines`）、`MaintenanceHomePage.tsx:288-296`。
- 下载需要**金额查看权限**（`data_profit`，管理员除外），否则 403「无金额查看权限」；上传还要求动作键 `action_maintenance_expense_collection_upload`——`backend/app/api/maintenance_project_master_workbook.py:234`、`backend/app/api/maintenance_expense_collection_workbook.py:94-108`；而前端按钮**无论有无该权限都会显示**，无权限账号点了才报错——`MaintenanceHomePage.tsx:288-296`。
- 表头只有 12 列：项目名称、合同编号、维保单号、制单日期、PN、产品描述、需求数量、退货数量、成本来源(系统)、未税单位成本、含税单位成本(系统计算)、变更原因；**没有**项目总表 03 的发货SN、出库仓库等列——`maintenance_project_master_workbook.py:112-114`（对比 `_PARTS_HEADERS` `:107-109`）。
- 回传只认补价一件事（改未税单位成本/变更原因），不能删行/作废/改数量——`maintenance_project_master_workbook.py:1187-1207`（`validate_global`）。
- 排序为制单日期倒序（需求00004 R4 正在讨论是否改升序）——`maintenance_project_master_workbook.py:492-493`；见 [需求00004](需求00004.md) §3、§5 #9。

### 3.3 可能的缺口（推测，待澄清确认）

结合截断句「下载全项目备件表就不需要在…」，较可能的几种诉求：

1. **不需要再逐个项目进去下载**：同事目前进每个项目下载项目总表/03 sheet，不知道或找不到主页的全局入口 → 入口可见性/位置问题（例如希望放在「需求单与同步」或数据分析页）。
2. **不需要再选时间段**：希望一键下全量，而现状必须选今天/昨天/本周/本月/自定义，且没有「全部」。
3. **不需要金额权限**：只想拿行级备件明细（PN/数量/单号），而现状下载强制 `data_profit`；按钮对无权限账号仍显示，会出现「点了下载失败」。
4. **不需要再到别处拼数据**：希望全局表带上 SN、出库仓库、领用/返还状态等列，或跟随主页当前筛选（业务类型/期限）导出。
