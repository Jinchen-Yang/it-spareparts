# ADR-0003：WBDD 整单逻辑删除、服务端双确认与防复活墓碑

- 状态：已接受
- 日期：2026-08-09
- 范围：来源维保单检索、成本与库存推导、项目视图、导出、往返工作簿

## 背景

历史导入中存在重复或不应继续参与经营计算的 WBDD。直接物理删除会同时破坏原始追溯、项目归属和审计；只在当前页面隐藏则会让成本、库存、导出等口径继续使用该单。跨页批量操作还存在误勾、页面倒计时被绕过和复核后源数据变化等风险。

## 决策

### 1. 删除单位和数据保留

删除单位固定为一张完整 WBDD 订单头及其全部明细的有效性，禁止删除单个 SKU 行。执行时只建立逻辑墓碑，不物理删除或改写：

- `f_maintenance_order` 与 `f_maintenance_line`；
- 原始上传文件和导入批次；
- 稳定项目归属；
- 历史删除、恢复及其他业务审计。

首版不把来源单 `data_status` 当删除标记，也不处理退货冲成本。

### 2. 唯一有效读边界

生效墓碑存在时，该 WBDD 必须同时退出成本重算、动态库存出库量、项目聚合与明细、逐单/项目/往返工作簿导出和候选清单。所有这些模型共用同一个 `NOT EXISTS active tombstone` 条件，不能由各页面自行判断。

通用 ETL 仍按 `raw_order_id` 更新保留的源订单和明细，但不会删除墓碑。因此重复导入相同 `raw_order_id` 只能更新原始追溯内容，不能使其重新进入有效读模型。

### 3. 跨页选择与不可变复核

检索只接受 POST JSON body，按订单号、项目、合同和 PN 召回，并保持“一张订单头一行”。前端以 `raw_order_id` 保存跨页选择；单批上限为 1000 张订单头、20000 行明细。

删除意图保存：完整选择顺序、逐单版本摘要、订单号、日期、项目、行数、下游引用提示、操作人、理由、创建/过期时间和不可变选择摘要。逐单版本由订单头和全部明细的规范化内容计算；数据库在建单时按父意图 `header_count` 锁定条目数量，清单满额后拒绝继续追加，并始终拒绝更新或删除既有条目。

意图的幂等键、请求/选择摘要、理由、操作人、数量和创建/过期时间同样由数据库触发器禁止改写；状态机只更新状态、等待时间、结果和终止时间，不能在第一次复核后偷换清单身份。

### 4. 服务端状态机和原子执行

状态机为：

```text
reviewed → armed_wait → executed
                  ↘ conflicted / expired / cancelled
```

第一次确认由服务端写入 `not_before = server_now + 7 seconds`。第二次确认早于该时刻必须返回 HTTP 425；前端倒计时只作提示，不是授权依据。

执行与导入共用事务级 advisory lock，并对删除意图、订单头和明细加锁后重新计算全部逐单版本。摘要错误、重复 ID、缺失/已删除订单、任一版本变化、操作人或权限变化都使整批零删除。重复执行同一意图返回同一结果，不追加第二条执行事件。

### 5. 权限、审计与恢复

搜索需要 `page_maintenance`。删除使用独立高风险权限 `action_maintenance_demand_delete`，默认只给管理员；所有写端点还必须由数据库中的有效实名 `SysUser` 发起，共享口令、fallback、匿名和旧来源不明 token 一律失败关闭。

删除、冲突、取消、过期和恢复写入追加式业务事件，至少保留稳定 ID、条目/行数量、理由、结果和操作人。搜索词不写访问审计或运行日志。

恢复是独立实名管理员动作：关闭当前墓碑并追加恢复事件，不删除历史意图或事件。由于删除期间来源行可以重导、采购/销售取价证据也可以变化，恢复事务必须先清空该单全部派生成本与取价 provenance，并写入 `cost_recompute_pending`；因此恢复后只会以“待重算”重新进入有效读模型，旧价不会短暂冒充当前成本。下一轮正式成本重算会基于当前证据重建成本并移除该标记。后续再次删除会产生新意图和新事件。

## 后果

好处是所有业务模型对“该 WBDD 是否有效”有同一答案，误操作可以恢复且不会丢失原始证据；前端篡改倒计时或并发重导也不能造成部分删除。

代价是任何新增的 WBDD 读模型都必须接入有效读边界；删除和导入会在很短的事务窗口内串行。逐单全内容摘要也使成本重算等派生字段在复核后变化时安全地触发整批重新复核。

## 不在本决策范围

- 物理清理原始订单、明细或归档；
- 修改稳定项目归属；
- 自动恢复、按名称重建关联；
- 退货冲减成本；
- 真实生产数据清理与生产部署。
