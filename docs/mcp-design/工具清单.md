# MCP 工具清单

共 19 个设计工具。M1 为首版核心，M1-optional 可裁剪，M2 首版不注册。所有工具均尚未实现。

| 工具 | 用途 | 阶段 | 副作用 | 开发缺口 |
|---|---|---|---|---|
| `pf_get_capabilities` | 查询身份与已开放能力 | M1 | query | 新增family与工具注册表；仅披露当前用户可见能力，不输出密钥/全局配置 |
| `pf_create_upload_session` | 创建文件暂存会话 | M1 | staging | 新增真实二进制上传通道；工具不接受local_path或URL抓取；会话生成不等于上传 |
| `pf_get_upload_session` | 查询暂存文件状态 | M1 | query | 新增会话/文件登记与逐项校验状态 |
| `pf_inspect_document` | 查看文件结构与单据分类 | M1 | query | 复用确定性识别器+文件ACL；family识别不写业务；默认不返回客户全文，样本经字段权限校验，不确定不推断 |
| `pf_search_projects` | 定位员工可见项目 | M1 | query | 抽取现有范围过滤；不能仅凭名字自动归属；关闭发布闸时不绕过 |
| `pf_preview_import` | 创建持久导入预览 | M1 | staging | 适配各族原生预览；未实现dry-run的family返回unsupported；混合family先拆分，业务写入次数必须为0；upsert仅获明确修复意图时使用 |
| `pf_get_import_preview` | 读取预览详情和逐行问题 | M1 | query | 新增持久预览统一读模型，不泄露其他人的预览；分页不隐去存在更多作废行的事实 |
| `pf_open_review` | 生成登录审阅入口 | M1 | query | 新增网页绑定冻结预览，GET不创建批准；真实确认在浏览器业务登录后POST，待实现不能返回虚构链接 |
| `pf_get_job` | 查询任务与处理回执 | M1 | query | 统一持久任务所有权/结果未知状态，不暴露原接口全局作业列表 |
| `pf_get_export_options` | 查询允许导出的模板与字段 | M1 | query | 按账号与发布闸生成受限注册表；模板全额权限不足则不提供该模板 |
| `pf_create_export` | 生成业务导出任务 | M1 | artifact | 字段/日期/项目范围在服务端验证；完整往返模板拒绝任意fields或日期裁剪，不降级成普通报表；产物有权限来源 |
| `pf_get_download` | 获取权限保护的下载入口 | M1 | query | 返回登录链接，不返回服务器路径或原始PAT；真实下载端再验权/记录流状态 |
| `pf_get_project_materials` | 查看项目材料与已知缺项 | M1-optional | query | 新增受限聚合；未配置要求不能声称缺失；无费用行不能推断零费用或已完整 |
| `pf_search_parts` | PN与描述查询 | M1-optional | query | 允许列表投影，默认无价格/供应商/客户；适配性仅引用已维护记录 |
| `pf_get_inventory` | 批量查询配件库存 | M1-optional | query | 实际API映射与库存字段口径适配；不把需求、发货候选、领用当库存，不宣称实时可承诺库存 |
| `pf_get_price_reference` | 查询授权内历史参考价格 | M2 | query | 数据权限与own_customers_only；不对缺失价格补0或暗中扩大查询窗口 |
| `pf_search_audit` | 检索本人或授权范围审计 | M1 | query | 新增可靠事件存储；actor参数只做过滤不能提升权限，self/all独立判定；最长31天/次，响应本身脱敏 |
| `pf_apply_import` | 提交服务器已确认的预览 | M2 | business_write | 首版不注册；网页确认记录绑定预览/行集，原生事务收据/outbox/幂等全部完成后开放 |
| `pf_retry_job` | 重试明确未提交的失败项目 | M2 | business_write | 首版不注册；先查receipt，未知提交不得重放；权限/版本改变须重预览确认 |

输入与返回字段见 [tool-catalog.json](tool-catalog.json)。文件上传会话、预览和产物虽然不改业务事实，仍会产生持久化副作用，不标成只读。审计等内部必要副作用不改变查询工具的业务只读分类。
