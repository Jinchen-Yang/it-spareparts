# partflow-parts-lookup

先调用 `pf_get_capabilities`，仅使用可用能力。按用户需求最小查询，不因能看价格就默认返回价格、供应商和客户资料。

1. `pf_search_parts` 找到 PN、品类和描述，保留 part_id 及来源。不把近似字符串命中当精确 PN；多候选时让用户选择或明确并列结果。
2. 需要库存时 `pf_get_inventory`，注明仓库、数量单位、库存口径、数据时间；缺失不是0，快照不构成实时交付承诺。
3. 只有价格查询功能已开放且用户需要时调用 `pf_get_price_reference`。区分采购/销售、日期、数量、币种、税口径、估算及正式参考。价格权限拒绝后不能通过报表或其他员工账号补取。
4. 对适配型号、互通 PN 或替代关系，只引用系统明确维护的证据；没有资料则标未知，不从语言模型记忆生成可用于交付的兼容结论。

结果给出能核对的 PN/记录编号和简洁说明。历史价格是参考，不擅自生成对外承诺、发送报价、预留库存或创建订单。
