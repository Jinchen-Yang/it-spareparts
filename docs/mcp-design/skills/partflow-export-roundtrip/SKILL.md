# partflow-export-roundtrip

先调用 `pf_get_capabilities` 与 `pf_get_export_options`，区分普通只读报表和可回传工作簿。工具不存在或模板被禁用时说明原因，不从其他工具拼凑绕过。

1. 从用户请求取得项目、日期和用途；缺少影响范围的条件时澄清，不默认全公司或所有月份。通过 `pf_search_projects` 定位稳定项目 ID。
2. 调用 `pf_create_export`，只选服务端允许的字段和模板版本。往返工作簿不任意加日期过滤或删列；权限不足拒绝完整模板时，可按用户实际需要选择另一个允许的只读报表，明确它不能回传。
3. 用 `pf_get_job` 查询产物，`pf_get_download` 获取受保护下载入口。通过验证过的本地下载能力或登录网页下载；不得输出服务器磁盘路径当作员工可用链接。
4. 保存到指定目录并核验可获得的大小/哈希，输出文件名、覆盖范围、数据时间、模板版本和下载状态。仅服务器生成完毕时称“已生成”；无本地保存证据时不称“已保存到电脑”。

用户编辑往返表时保留固定 Table、行 ID、版本、签名、公式和隐藏技术表；依据该 protocol 返回的 mutation_semantics 解释删行/作废。未经明确要求不删行，不把“排版整理”解释为重建整本工作簿。只读报表需要防公式注入；不得为防注入破坏官方模板原有合法公式。

回传生成新 file_id，重新识别和预览，不复用旧 approval。空报销不证明费用为零或完整；WBDD 录入辅助导出不称可直接导入氚云。
