# 采购分析面板 + 含税未税改造 + 采购来源渠道 · 部署说明

本次变更（早会/周会采购分析工具）的上线步骤。库存动态化、利润计算本轮不涉及。

## 一、变更概要

- **迁移 `d7a4f1c9b3e2`（additive，可逆）**：`f_purchase_order` 加 `is_tax_inclusive / tax_amount / amount_inc_tax`；`dim_supplier` 加 `source_channel`。新列均可空，不回填、不改既有行。
- **ETL**：导入层补接氚云采购订单的 `是否含税(必填) / 税金 / 采购金额`，按订单口径把行单价归位；税率列常空时由 `税金/不含税金额` 反推（限 `[0,1)` 防溢出 `Numeric(5,4)`）。供应商按名派生 `source_channel`（淘宝/京东/个人/正规供应商）。
- **服务/接口**：`services/purchase_analysis.py` + `GET /purchases/analysis`、`GET /purchases/analysis/part`（均 `require_page("page_purchases")` + 字段脱敏）。
- **前端**：采购记录页顶部「采购分析」面板（可折叠），含税未税切换、来源渠道拆分、逐笔横向比价下钻。
- **权限**：`source_channel`/`channel` 已登记进 `FIELD_GROUPS["supplier_info"]`，随 `data_supplier=False`（销售）一并遮蔽。

## 二、上线步骤（沿用 DEPLOY.md §十一 升级路径）

```
备份 → pull → build(顺序 app 再 frontend) → 迁移 → up → 验证
```

1. **备份**：`backup.sh`（pg_dump，已有 cron）。
2. **拉代码**：`git pull`（合并本 PR 后）。
3. **构建**（4C8G 顺序构建防 OOM）：`docker compose build app` 再 `docker compose build frontend`。
4. **迁移**：`docker compose run --rm app alembic upgrade head`（旧容器继续服务，零登录失败窗口）。head 应到 `d7a4f1c9b3e2`，单头无断链。
5. **起容器**：`docker compose up -d`。
6. **验证**：登录 admin → 采购记录页应出现「采购分析」面板；`GET /api/purchases/analysis?days=7` 返回 200。

## 三、⚠️ 关键：上线后重导一次采购填充新列

新列加迁移时为 **NULL**（additive 不回填）。`is_tax_inclusive`/`source_channel` 要有值，**必须把全量采购 Excel 重导一遍**：

- 走「数据导入」页上传采购订单 Excel（或导入作业批量上传）。`mode=skip` 即可——loader 的 `source_channel` 用 fill-if-empty（coalesce），NULL → 新值会被填上；订单头新列在 upsert 路径填充。
- 重导后核验：`SELECT is_tax_inclusive, count(*) FROM f_purchase_order GROUP BY 1`（应分出 含税/不含/NULL）；`SELECT source_channel, count(*) FROM dim_supplier GROUP BY 1`（应见 淘宝/京东/个人/正规供应商）。
- **重导前**：含税未税切换、来源渠道拆分会显示空/未分类（口径列未填），属预期，不是 bug。

## 四、口径与已知边界

- **不含税采购的「含税价」故意留空（显示 "—"）**，不按 13% 估（用户口径）。
- **`供应商类型` 不参与渠道分类**：实测几乎人人都是「底层回收商」，按它分会把所有供应商归成「回收」，失去意义。渠道纯按供应商名派生；`回收/维修` 信息仍在 `dim_supplier.supplier_type` 列。
- **`source_channel` 用 fill-if-empty**：首次重导能填上 NULL；若后续要**重新分类**（改了关键词规则），fill-if-empty 不会覆盖旧值，需手动清空对应供应商的 `source_channel` 再重导，或走人工修正。
- `is_tax_inclusive=None`（未知）会并入未税聚合——实测真实导出该列 100% 有值，不会发生。

## 五、回滚

迁移可逆：`alembic downgrade -1` 删除四个新列（已验证 up↔down 往返）。前端面板纯增量，回退前端镜像即可。
