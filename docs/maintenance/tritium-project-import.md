| 字段 | 来源系统 | 更新方式 | 说明 |

| 项目名称 | 氚云 | 导入时更新 | IT_data 中存为 display_name |
| 订单金额 | 氚云 | 导入时更新 | 合同总额 |
| 维保起止日期 | 氚云 | 导入时更新 | 服务期限 |

| 费用报销 | 氚云 | 导入时创建 | BXD 费用事实，不进入成本直到审批完成 |

## 导入策略

1. **幂等键**：`订单编号`（XSDD）作为稳定来源 ID
2. **匹配规则**：导入时先按 XSDD 查找已有项目，找到则更新"氚云拥有"的字段；未找到则创建新项目
3. **不覆盖字段**：`project_manager_id`（维保负责人系统绑定）不由导入更新
4. **金额解析**：Excel 序列号日期 → ISO date；中文回款日期 → YYYY-MM 格式
5. **回款计划**：7组回款时间+金额，只导入非空组
6. **冲突处理**：同一 XSDD 并发导入 → 409 conflict
7. **错误处理**：缺 XSDD / 重复 XSDD / 非法金额 → 整批零写入
