# 无单号的现场领用回传

2026-09-09 业务确认：没有现场领用单号的实际领用也可以登记，由系统生成稳定编号；WBDD 是关联需求单参考，实际日期取用户填写的完整年月日。

## 新增与重复上传

- `06_领用返还` 新行：日期、PN、正数量必填，单号选填。
- 单号为空或为 `WBDD-YYYYMMDD-序号` 时，生成 `LY-AUTO-…` 编号，每一行保留一次领用。相同 PN、无 SN 的多行不会自动合并或删除。
- WBDD 独立存入领用明细的 `demand_order_no`，在新下载的总表中展示为只读「关联需求单号」。需求单价格参考继续按项目范围查询该关联号。
- 自动身份由项目、已签名导出 ID、行内容及相同内容的出现次数确定。同一本文件原样重传、调整行序均不重复新增。**首次导入后修改，应重新下载并保留实体 ID。** 原文件已完成自动编号后，再改动或追加无身份行会要求重新下载，避免重复入账；apply 锁内也复核该导出范围。不同导出文件不承诺对再次粘贴的无身份历史数据自动去重。
- 同一本旧文件重放遇到已被修改的自动编号事实时，提示重新下载；遇到已作废事实时遵守作废优先，不恢复该行。
- 已按旧规则入库的 WBDD 身份保持兼容，不自动迁移历史记录或批量改写历史日期。
- 有正式领用编号的重复单号/PN/SN 仍要求核实；提示不会要求业务直接删除可能代表不同次领用的行。

## 日期与核对

领用日期不能由单号内的日期覆盖；日期样式丢失的 Excel 数字序列按工作簿的 1900/1904 日期系统还原。缺少年份、仅有月份、空日期等需要业务补全。06 表预检集中报告日期、数量、是否应返还、缺失 PN 及未匹配型号，失败时整本不写入。

`backend/scripts/annotate_site_dates.py` 可生成仅增加日期批注和颜色的核对副本，不改变原值、行数、签名或实体 ID。副本不是已通过生产预检的文件，不能代替主数据匹配。
