## 1. 定位（一句话）

**后事实数据展示板**：业务发生之后，用已有的 Excel 数据让老板看清每个维保项目的「货」和「钱」——
重点是**项目成本**和**备件申请**。不是业务流程系统、不做闭环、不替代氚云，也不替代审批流
（唯一例外：补库购物车的系统三查，见 §8）。

## 2. 角色与权限

| 角色 | 权限 | 范围 |

| 老板/管理层 | `page_maintenance_boss` | 展示板全套、全部项目 |

| 数据权限 | `data_purchase_cost` / `data_profit` | 无权限时字段整块显示「受限」，**不显示 0、不显示空值占位** |

## 3. 业务对象与事实源（「货」和「钱」从哪来）

| 对象 | 事实源 | 进入方式 |
| --- | --- | --- |
| 维保备件需求单（WBDD） | 氚云导出 Excel（双表头：历史版 90 列 / 当前年度版 91 列） | 全量快照上传，按单号＋行覆盖 |
| 发货单（CKD） | 氚云机打单 | 预览 → 应用 |
| 退货返库单（return_order） | 氚云导出 | 预览 → 应用 |
| 入库单（RKD，坏品/废品返件类） | 氚云导出 | 预览 → 应用 |
| 台账工作簿 | 商务线手工维护 Excel | 预览 → 应用；项目/合同/期限/回款计划**唯一事实源** |
| 报销/回款工作簿 | 业务手工维护 Excel（AB-3，v1 新增） | `04_报销订单`＋`05_项目经理回款单` **两张 sheet 合一**，下载 → 本地增删改 → 上传覆盖 |
| 补库购物车申请 | 系统内记录（AB-4，解冻中） | 独立记录、挂所选项目、与项目其他内容**隔离**、只作记录展示、不进计算与对账 |
| 互通池 | 系统维护 | PN 池归属、池内最低价 |
| 项目身份 | **台账项目名（Excel 写法为准）** | 预交付＝单据前缀，剥前缀挂真实合同展示（不叫「合并」），打「预交付」徽标 |

## 4. 事实源分离（铁律）

- **实发** = CKD 发货单；**未用件收回** = 返库单（成品）；**坏件回收** = RKD 入库单（坏品/废品，返件类）。
- 需求单上的流转状态列（已采/待供/待返/领用等）**只原样展示，不计算、不标注**（氚云人工维护，不可信）。
- 返还率：分子 = 只有返件类（维保拆旧返件＋旧库退返）；分母 = 需求单「需求」数量（2026-08-16 业务口径）。
- 自报（需求单头列）与事实（三源）**并排展示，系统不判断差异**。
- 缺数据**不隐藏、只标注**：未导入 → 「尚未导入」（绝不显示 0）；成本无参照价 → 留空＋标来源；
  PN 未标准化 → 池归属显示「—」（不知道≠否定）；金额无权限 → 受限块。

## 5. 成本口径

- **取价瀑布**（生产覆盖 88.7%）：采购价优先（直采 / 采购历史 / 池内采购）→ 无采购用销售价
  （销售历史 / 池内销售）→ 同源时间就近窗口 → 月均兜底；每行如实标注来源。
- 看板成本字段正式名（M0-C）：「**已知申请估算成本(含税)**」；API 键固定中性
  `known_apply_cost_inc_tax`，改名只动前端文案。
- 报销正式金额列 = `amount_inc_tax`（含税计算值）。
- 缺失成本保持空值并标注，**不能按 0 处理**。

## 6. 归属与粒度

- 事实粒度（M0-D）：**项目＋PN 聚合**，不做需求明细行级分配（发货/返库明细无行级键）。
- 归属流程：候选生成（只出候选不自动写）→ 人工确认 → 未归属桶 → 预交付剥前缀挂靠。
- 归档项目（`is_active=false`）只要还带单就**出现在列表**并标「已归档」；已空掉的归档项目隐藏。
- 单据证据表里「自报（本单）」与「事实（项目口径）」两组列**不可直接相减**，列头与表尾已标注。

## 7. 上传与更新节奏

- **6 类 Excel**：需求单 / 发货单 / 返库单 / 入库单 / 台账 / 报销回款，按需每周或每月传。
- 需求单规则（F1）：全量快照 upsert；同文件重传幂等；上批有本批无 → 只进对账差异清单，
  **不删除不隐藏**；已取消/作废保留入库、原样展示、聚合不剔除。
  **修改通道 = 源头 Excel/氚云改后重传覆盖，系统内不手工编辑**。
- 数据陈旧提示（F2）：最新文件 as_of 距今 > 45 天 → 展示态标「旧」（只提示，不落库不改数据）。
- 每次上传产出**快照差异报告**（对账）。

## 8. 页面结构（2026-08-16 定稿 2 页，实现见 GitHub issue）

- **①维保主页（项目卡墙）**：筛选（进行中默认/已结束可筛、正常/提醒/报警）＋模糊搜索（项目名/单号）；
  一行 5 卡、下滑加载；卡片=标题/XSDD/项目经理/合同总额/小字（备件成本含税未税、缺失成本、
  维保备件采购数、回款预览）/进度条（v1 一条＝成本÷合同额，<80% 绿、80–100% 黄、>100% 红）；
  主页全局下载全项目备件行级表（今天/昨天/本周/本月/自定义），改价补价上传覆盖＝真实源。
  卡片状态三态=进度条颜色：正常=绿、提醒=黄（成本≥80% 合同额）、报警=红（>100%）；「需关注」=提醒，并入卡片状态。
- **②项目面板**：出库明细（按时间筛选；多合同并排或筛选）＋子 tab（基础信息/备件成本/报销/回款＝
  项目总表的 web 呈现）＋下载本项目总表（多 sheet）＋各 tab 下载对应单 sheet；项目名旁编辑基本信息。
- **一张总表改所有数据**：缺价/报销/回款都走下载→改→上传覆盖。
- 销售经理：补库购物车；admin：数据维护（单页多 Tab）。
- 原始单据上传（需求单/发货/返库/入库/台账）走 admin 既有「数据中心→数据导入」入口，不新建上传台；
  回填类下载上传只在主页和项目 tab 页。
- 旧页面（工作台 9 页、旧版 3 页、旧展示板 5 页）**直接删除代码**，新 2 页替换上线（先建新后删旧）。
- 冻结清单 9 项仍按「代码保留、导航隐藏、不上线」。
