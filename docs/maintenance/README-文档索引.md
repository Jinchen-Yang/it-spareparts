## 关键决策已锁定（不要再讨论）

1. 系统是**后事实展示板**，不做业务流程闭环；
2. 成本回填 = 采购价优先 → 无采购用销售价 → 时间就近（引擎已存在，复用）；
3. 需求单状态列只展示、不计算、不标注；
4. 预交付项目并入真实合同展示（不叫合并）；
5. 坏件回收 = 入库单返件类（维保拆旧返件/旧库退返）；好件收回 = 返库单成品；
6. 权限 = 勾选名单制；上传用 maintenance-only 专用端点；
7. 冻结清单（AI 兜底/购物车/凭证/变卖/工作簿导出/前置库页/销售看板/报销对账）不上线。
