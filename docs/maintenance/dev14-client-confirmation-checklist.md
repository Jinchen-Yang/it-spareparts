# 维保合同级毛利口径确认记录

状态：**已确认**（2026-07-29）。

本文件保留 DEV-14 阶段向甲方提出的问题及最终答复，作为需求追溯记录。实现、验收和发布的
当前权威规范为
[DEV-15 往返工作簿与税务口径规范](./dev15-roundtrip-and-tax-policy-spec.md)。

由于一张 XSDD 销售合同可能关联多个维保项目，而系统没有可审计的项目收入分摊依据，
本期正式名称统一为“合同级备件毛利”和“合同级贡献毛利”，不发布单项目毛利。

## 甲方确认结果

| 序号 | 确认后的统一口径 |
|---|---|
| 1 | 两个指标都保留：合同级备件毛利 = 合同收入 − 备件成本；合同级贡献毛利 = 合同收入 − 备件成本 − 维保报销费用。 |
| 2 | 上传表格存在明确税务字段时以该字段为准；没有字段说明含税或未税时，原始金额统一认定为未税，同时按固定税率生成并保留含税、未税两套金额。 |
| 3 | 采购和销售统一按 13% 税率换算。 |
| 4 | 只有管理员可以分别设置采购、销售、项目维保的含税/未税/同时显示口径；普通用户不能切换；销售默认显示未税。 |
| 5 | 页面选择日期只用于导出对应闭区间内的订单、明细和报销，不改变页面毛利计算口径。 |
| 6 | 同一销售订单号存在多个版本时，采用最新一次成功导入且当前有效的版本。 |
| 7 | 本期只计算合同级毛利，不做合同内多项目收入分摊。 |
| 8 | 成本参考可使用全部当前 active 的互通 PN 池，不要求审批。 |
| 9 | 池内没有采购记录时允许参考销售记录，作为低置信成本估算并保留来源证据。 |
| 10 | 采用系统固定的维保往返工作簿模板，不再依赖工作人员自行组织列和工作表。 |
| 11 | 自动参考范围限定为出库日前三个月；池采购、池销售、本 PN 采购、本 PN 销售均无可用数据时，进入人工成本回填。 |
| 12 | 系统提供稳定、美观且机器可读的往返工作簿；工作人员可导出后维护订单、报销和人工成本，再整体导回系统更新。 |

## 最终业务规则

- 含税和未税金额同时保存，管理员设置只控制展示，不改写历史数据。
- 只补当前成本缺失行；已有真实成本来源的历史行不因参考价变化而被静默重估。
- 补价顺序固定为：池采购均价 → 池销售均价 → 本 PN 历史采购 → 本 PN 历史销售
  → 人工回填。
- 自动参考只读取出库日当日或以前、且位于前三个自然月内的有效记录，不读取未来数据。
- 全部 active 池均可参与参考；若一个 PN 同时属于多个 active 池而无法唯一判定，则池级参考
  失败关闭，继续尝试本 PN 历史记录。
- 均价按数量加权；池价和销售参考价标记为低置信估算，并保存池、样本月份、样本数和追溯月份。
- 收入、成本或费用证据不完整时，对应毛利保持空值并提示补数据，不使用 0 或另一税务口径伪造。
- “没有报销记录”不等于“报销费用为 0”。只有无日期范围的完整往返工作簿成功回填并建立
  费用完整快照后，才能发布合同级贡献毛利。
- 日期范围仅限制导出的行；带日期范围的往返工作簿不得声明合同费用已形成完整快照。
- 所有往返写入都必须经过模板版本、合同/日期范围、行版本和重复导入校验，并保留审计记录。

## 固定模板组成

固定工作簿包含以下工作表：

1. `00_使用说明`
2. `01_项目`
3. `02_维保订单`
4. `03_订单明细`
5. `04_报销明细`
6. `05_人工成本回填`
7. `98_字典`
8. `99_合同版本`
9. `99_元数据`

工作人员只编辑模板标明的输入列，不修改内部 ID、版本、合同范围和元数据。系统按工作表及
业务主键执行受控新增、更新或作废；不接受自由格式 Excel 直接覆盖业务数据。
