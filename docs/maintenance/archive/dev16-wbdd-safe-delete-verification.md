## 已验证行为

### 服务端安全边界

- 检索只接受 POST JSON body，按 WBDD 单号、项目、合同和 PN 返回“一张订单头一行”。
- 跨页选择使用稳定 `raw_order_id`，单批限制 1000 张订单头、20000 行明细；1001 项、空白/非字符串/超长稳定 ID 都返回无输入回显的通用 422，重复 ID 整批拒绝。
- 服务端冻结完整逐单快照与 digest；数据库阻止意图身份改写，并在条目数达到 `header_count` 后阻止追加，同时禁止条目更新/删除。
- 第一次确认由服务端生成至少七秒的 `not_before`；6.99 秒返回 425，满七秒才允许第二次确认。
- 执行与导入/成本写入共用事务锁；任一逐单版本变化、摘要错误、操作人不符或权限失败都会整批零删除。
- 执行只建立 tombstone，保留订单头、全部明细、导入归档、历史成本证据和追加式审计；相同 `raw_order_id` 重导不会复活。
- 恢复仅允许实名管理员；恢复事务先清空全部派生成本与 provenance，并写入 `cost_recompute_pending`，下一轮正式重算再使用当前取价证据恢复成本。
- 搜索长词、批量稳定 ID、恢复理由和恢复路径 ID 的拒绝响应及日志/业务审计均不回显敏感输入。

### 有效读模型

生效 tombstone 会把整张 WBDD 从以下读模型同时排除：

- 维保成本重算和项目成本聚合；
- 动态库存维保出库量；
- 维保项目/明细读取；
- 标准导出、按合同工作簿与固定往返工作簿；
- 往返回填所使用的订单、明细和人工成本候选。

现场领用事实属于稳定项目经营事实，不是 WBDD 需求量，本功能不会删除或抵消现场领用。
