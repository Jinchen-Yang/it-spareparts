# 维保 Excel 工作簿模板设计（v1）

> 状态：设计稿 v1（2026-08-15）。配套产物：`docs/maintenance/templates/` 下两份可打开编辑的
> .xlsx 模板 + 生成脚本 `scripts/gen_maintenance_workbook_templates.py`。
> 本文档只覆盖「非氚云机打单」的 Excel：台账工作簿（业务手工维护）与项目工作簿（系统生成→人工回填→上传）。

## 1. 背景与结论

- 氚云机打单（发货单 CKD / 入库单 RKD / 退货返库单 / 费用报销支付单 BXD）格式由氚云决定，
  走 py 规则 adapter（字段码优先），**不套用本模板**。
- 系统当前存在三套往返工作簿（合同级九表 roundtrip、项目四表 v2、经理月报 v3）+ 一份旧合同
  成本工作簿 + 台账工作簿。字段重叠且互相割裂，是「下载/上传/看板脱离」的代码根源。
- 台账工作簿现状最痛：`维保项目清单` 64 列，其中 48 列是「回款时间N/回款金额」横向对（24 组），
  横向无限扩展是 py 解析漂移的典型来源。

## 2. 统一原则

1. **两本工作簿**，不新增第三类：
   - `维保台账工作簿模板_v1.xlsx`：商务线唯一来源（项目/合同/回款计划/报销归集），业务手工维护；
   - `维保项目工作簿模板_v1.xlsx`：项目级台账视图，系统下载 → 表尾回填 → 整本上传。
2. **颜色契约**：灰底表头 = 系统生成只读；黄底表头 = 可编辑/可追加。上传解析只认黄底列，
   灰底列即使被改也忽略——这比任何「格式校验」都抗漂移。
3. **缺行 ≠ 删除**：只有「操作」列 VOID 才作废业务行（沿用 DEV-15 语义）。
4. **隐藏技术 Sheet**（98_字典 / 99_元数据）：放稳定 ID、行令牌、协议版本，用户看不到也不编辑。
5. **回款纵向化**：废止横向 N 组回款列，一期限一行。
6. **日期规范**（见 §7）：完整日期 `YYYY-MM-DD`，年月期间 `YYYY-MM`；中文写法可识别但不推荐。

## 2.1 两本工作簿的同步方向（已确认，2026-08-15）

两本模板存在故意的交叉列，同步方向是**单向**的，不存在任何一列在两处都可编辑：

```
台账工作簿（手工维护）＝商务线唯一事实源
  └─ 项目/合同/维保期限/CMO/项目经理/回款计划/报销归集
        ↓ 导入系统库
        ↓ 系统按项目生成「项目工作簿」：交叉列全部灰底只读
项目工作簿回填列（成本回填、月度累计回款、凭证、领用行不返还标记、备注）
        ↓ 上传 → 只写系统库（事实层/核算层），不回流台账
```

- 台账管「计划」（项目、合同、回款计划节点）；
- 项目工作簿管「实际 + 回填」（备件订单事实、报销事实、月度累计回款快照、领用行标记、人工成本）；
- 交叉列（项目名称、期限、合同号等）在项目工作簿中只读，杜绝双写冲突。

## 3. 项目工作簿（每项目一本）Sheet 规格

### 01_项目基础信息（全只读）
| 列 | 来源 |

| 项目编号 / 项目名称 / 业务类型 / 客户名称 | 台账同步 |
| 维保开始日期 / 维保结束日期 | 台账（项目名称内嵌期限时拆出） |
| 项目经理(CMO) / 维保负责人 / 销售人员 | 台账 + 负责人分配 |
| 硬盘不返还默认值(项目级) | 项目级默认标记；**行级标记在 06 表逐行填写/覆盖** |
| 项目状态 | 系统（服务中/已结项/期限待确认） |
| 前置库种类数 / 前置库件数 / 前置库金额(含税) | 前置库账本上线前固定显示「尚未接入」 |

### 02_概览数据（全只读）
- 一、合同清单：合同编号、合同额(含税)、原始合同状态、状态映射、是否计入总额、生效/失效日期、金额完整性
- 二、关键指标：合同总额(含税)、累计回款(含税)、回款进度、项目已计成本(含税)、**成本率（进度条口径）**、
  缺失成本行数、前置库存金额(含税)、超90天未领用备件行数、数据完整性提示。
- 口径：缺数据的行照常展示，缺失仅提示（不隐藏、不按 0 计）。

### 03_备件订单（黄底可编辑：未税单位成本、变更原因）
| 列 | 来源 |

| 成本来源(系统) | 取价瀑布结果 |

| 变更原因 | 人工回填（黄底） |

### 04_报销订单（黄底可编辑：未税金额、备注）

**未税金额（黄底）** / 含税金额(系统计算) / 流程状态 / **备注（黄底）**。

### 05_项目经理回款单（月度累计快照，表尾追加；黄底：操作、报告月份、累计回款金额、回款凭证号、备注）
操作(CREATE/VOID) / 合同编号 / 报告月份 / 累计回款金额(含税) / 回款凭证号 / 状态(系统) / 备注。

### 06_现场领用与返还（行级不返还标记；黄底：是否应返还(行级)、备注）

## 6. 已确认决策（2026-08-15）

1. 硬盘/备件不返还：**行级默认**——项目级提供默认值（01 表），领用行级可覆盖（06 表），返还率按行级排除。
2. 回款单口径：**月度累计快照**（报告月份 + 累计金额）。
3. 回款计划事实源：台账 `02_回款计划` 为**唯一来源**，与经理月报 v3 计划节点合并，项目工作簿只读展示。
4. 前置库三列：账本上线前固定显示「**尚未接入**」。

## 7. 日期与中文年月日防坑规则

台账与回填文件里真实存在 `2026年10月`（无日）、`/`、`、`、全角字符、Excel 日期序列号混排，
解析层必须做归一化，否则导入会静默丢行或错位。规则：

1. **模板约定**：完整日期列写 `YYYY-MM-DD`；仅有年月的期间列写 `YYYY-MM`（示例已按此生成）。
2. **导入层归一化**（必须实现，顺序执行）：
   - Excel 原生日期类型（datetime / 序列号）→ 直接取年月日；
   - 中文「YYYY年MM月[DD日]」→ 拆年月（无日则默认当月 1 日并打「仅到月」标记）；
   - `YYYY/MM/DD`、`YYYY.MM.DD`、`YYYY-MM-DD`、顿号、全角数字 → 统一；
   - `、`、`/` 单独占位 → 视为空；
   - 无法归一化 → 进异常清单（报行号+原值），**不静默跳行、不猜值**。
3. **展示层**：导出统一 `yyyy-mm-dd` 数字格式，避免「文本 vs 日期」混排再次污染下一轮导入。
