基线为 `319e25f6`，仅实现第 1–4 款。复用 `summarize_demand_returns`；免返不调整 N/R，本轮不发布返还状态。

三路核对：页面目前单笔支持关联、批量录入未传需求单；标准导入直接写台账且整批提交；工作簿返还表和 recovery 仅读取，通用 RKD 导入仅新增未关联实收。领用候选也消费旧 `demand_candidates`，容量过滤仅用于返还候选，不能误伤领用。
