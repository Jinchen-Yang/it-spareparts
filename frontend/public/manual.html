IT 备件智能管理系统 · 使用说明

一句话：把你在氚云里的进货、销售、库存表整理到一处，让报价、看行情、算利润变得又快又准。

这套系统能帮你做什么

  • 型号自动对齐。同一个东西在不同单子上写法五花八门，系统能认出来是同一个，不再各算各的。
  • 一个型号，一页看全。进过几次货、什么价、卖给谁、还剩多少库存、能赚多少——全在一页。报价、压价、跟客户解释，都有依据。
  • 报价不再翻表格。搜型号看行情，或者把客户发来的询价单直接丢给 AI 助手，几秒钟出一张带价格的报价单。
  • 老板看得清。哪些型号、哪个客户、哪个销售最赚钱，一目了然。

怎么登录

  • 账号哪来：管理员给你开一个（用户名 + 密码）。忘了密码，找管理员重置。
  • 登录：打开系统网址，输用户名和密码就进去了。登录后大约管半天（12 小时），过期了再登一次即可。
  • 多台设备：公司电脑、家里电脑、手机，可以同时登同一个号，互不影响。
  • 右上角会显示你的名字和身份（销售/采购/老板/管理员）。你能看到哪些功能，取决于你的身份。
如果管理员改了你的密码、调整了你的权限、或停用了你的账号，你这边会立刻退出登录——重新登一次就好。

按角色快速上手

不用全看完。先认准你的身份，常用的就这几件事：

销售

  1. 「型号查询」搜型号 → 看行情、给客户报价
  2. 客户发来询价单？丢给「AI 助手」批量报价
  3. 「采购记录」看最近进价心里有底

采购

  1. 「采购记录」看最近都从谁那儿、什么价买了啥
  2. 「型号查询」看某型号的历史进价、供应商
  3. 「库存查询」看还剩多少、要不要补货

老板

  1. 「利润分析」看哪些型号 / 客户 / 销售最赚钱
  2. 「型号查询」随手查任意型号的全貌
  3. 关注利润率偏低或亏本的型号

管理员

  1. 「账号管理」给员工开号、设权限
  2. 「数据导入」定期把氚云的表导进来
  3. 「数据治理」把型号口径理干净

谁能看到什么

不同身份能用的功能、能看到的数字不一样。尤其销售看到的客户和成交是受限的，目的是防止内部抢单、泄露货源。

身份能用的功能能看到的数字（重点）
管理员全部（含账号管理、数据治理）全部
老板除账号管理外几乎全部全部生意数据
销售型号查询、采购记录、AI 助手、库存等能看进价和利润（整机加点直卖要用到）；看不到供应商是谁；只能看自己客户的逐笔成交，同事的客户名隐藏；看不到「谁卖得多」这类排名
采购型号查询、采购记录、库存等偏采购侧的行情与进价
只读各种查询功能只能看，不能改
看不到某个功能？说明你的身份没开这个权限，正常现象。需要的话找管理员开。

型号查询

人人可用
用它来：搜一个型号，一页看全它的进货、销售、库存、成本、利润和可替代型号——报价、压价、跟客户解释，全靠它。

怎么搜

  1. 在搜索框里输型号或关键词，比如 希捷 8T、三星 960G 固态，回车。
  2. 搜不准也没关系：型号记不全、输错一两个字符、连字符不一样（4089RT 和 4089-RT）、品牌写中文还是英文（超微 / super），系统都能帮你找到。
  3. 结果按「像不像」从高到低排；如果系统觉得没把握，会提醒你「没有可靠匹配」，请自己挑一下，别瞎选。
  4. 点结果里的型号，就进入这个型号的「全貌」页。

型号全貌里能看到

  • 基本信息（描述、品牌、品类、规格参数）
  • 最近 20 笔进货（供应商、单价、日期）和最近 20 笔销售（客户、单价）
  • 各个仓库的库存、这个型号的可替代型号
  • 平均成本和利润率、历史询价大概区间、最近 90 天卖货快慢
举个例子：客户问「你们 8T 希捷硬盘什么价」，你搜「希捷 8T」点进去，最近进价多少、之前都卖多少、还有几块库存，一眼就清楚，报价心里有底。

采购记录

销售 / 采购 / 老板 / 管理员
用它来：看「最近都从谁那儿、用什么价、买了些什么」，所有型号的进货流水按时间倒着排。
  • 可以按时间看：近 7 天 / 30 天 / 90 天 / 近一年。
  • 可以按关键词（型号、描述、品牌）或供应商名字筛。
  • 每条显示：日期、型号、描述、品牌、数量、单价、金额、供应商、采购员、单号。

AI 助手

开通了「AI 助手」的身份
用它来：用大白话问，或把客户的询价单 / 配置单直接丢给它，它帮你查价、出报价单——最省事的报价方式。

三种用法

  • 直接问：「ST8000 最近进价多少」「这个型号近 90 天卖得怎么样」「帮我找个能替代它的型号」。
  • 丢文件给它：客户的 Excel 询价单、Word / PDF 配置单，甚至拍照或扫描件都行，它会一项一项帮你查价。
  • 让它出单：在你的模板上把价格填进去，或新建一张漂亮的报价单 / 报表，给你下载链接。
它会一个字一个字地回答你，还会显示「它查了哪些数据」，看得见、信得过。你切去别的页面它也在后台接着干，回来能接着看；想换个问法，随时打断重问。
你上传的、生成的文件只有你自己能看到和下载（报价、合同这些都是隐私），别人拿到链接也打不开。

库存查询

开通了「库存」的身份
用它来：看每个型号在各个仓库还剩多少，以及这些库存值多少钱。
  • 每条显示：型号、仓库、可用数量、安全库存、单位成本、这堆库存的总金额。
  • 可按仓库或型号/描述筛。
  • 手动修正：盘点对不上时，点行末「修正」，可以改实际数量或设安全库存。改的时候要写一句原因（系统会记下来谁改的、改成多少），保存后立即生效；也可以一键撤销、回到原始数量。
显示的可用数量 = 氚云里的原始数量 + 你手动修正过的部分。所以盘点差异修正后，这里看到的就是最准的实际库存。

利润分析　老板 / 管理员

用它来：看哪些型号、哪个客户、哪个销售最赚钱，营收、成本、利润、利润率一目了然。
  • 可以三选一地看：按型号 / 按销售员 / 按客户。
  • 系统用两种通行的算法分别算成本（一种按最近进价滚动平均、一种「先买先卖」），两个结果并排给你参考——不用纠结哪个对，看大方向即可。
  • 可按时间范围看；打开「只看异常」能单独挑出零价、金额对不上、没成本、亏本这些需要留意的记录。
  • 导入了新数据，点一下「重算」就能刷新所有成本和利润。
  • 能导出表格，拿去做汇报。
「按销售员 / 按客户」会暴露同事的经营情况，所以销售看不到，这个功能只给老板和管理员用。

数据导入　管理员 / 有导入权限的人

用它来：把氚云导出的采购、销售、库存、询价 Excel 导进系统，之后所有功能才有数据可用。

怎么导

  1. 把 Excel 文件拖到上传区（或点一下选择文件）。可以一次选多个一起传。
  2. 系统自动识别这是采购还是销售还是库存表，整理后存进去。文件大也不用干等，后台处理 + 进度条。
  3. 导完给你一张报告：成功几条、跳过几条、哪几行有问题（个别坏行会被单独挑出来，不影响其它正常的行）。
  4. 下面「导入历史」能回看每一次导入（谁导的、什么时候），点「详情」看那次的报告。
默认是「跳过模式」：同一个文件导过了就不会重复导，放心传。只有当氚云里改过数据、想让重新导入覆盖更新旧记录时，才需要打开「修复模式」。

数据治理　管理员

用它来：把型号的口径理干净——同一个东西的不同写法合并成一个，报表和利润才算得准。
  • 合并同款：系统会找出「看起来是同一个型号的不同写法」并给出建议，你确认一下就合并到一个标准型号（可以一条条确认，也可以批量确认）；万一合错了能撤销。合并后，两边的进货销售历史会自动归到一起。
  • 排除非标型号：把不该算进营收利润的杂项型号标记「排除」。
  • 处理数据问题：系统发现的缺字段、异常等问题会列出来，你逐条处理。
建议的做法：先来这里把型号合并归一、理干净，再去「利润分析」看报表，数字才靠谱。

账号管理　管理员

用它来：给员工开号、改密码、停用、设权限，以及看某人最近都登录、操作了什么。
  • 开号：填用户名、初始密码、身份（销售/采购等）、显示名；还能在身份的默认权限上，逐项勾选他能看哪些功能、哪些数字。
  • 改密码 / 停用 / 改权限：一旦改动，对方正在登录的设备会立刻被退出，需要重新登录（这样改动马上生效）。只改显示名不会踢人。
  • 看活动：查某个账号最近的登录和操作记录（含从哪台电脑登的），以及这个账号被谁改过。
管理员（admin）账号受保护：不能被改身份、不能被停用、权限永远全开，防止误把自己锁在门外。

小技巧

  • 列太窄看不全？用鼠标拖动表头右边的那条竖线，就能把这一列拉宽看全文；拉好的宽度下次还在。列很多时表格能左右滑动，不会把内容切掉。
  • 搜型号别背全。关键词 + 错一点也能搜到；实在拿不准，让 AI 助手帮你认。
  • 多台设备随便用。公司、家里、手机同时登一个号都行。

常见疑问

遇到的情况怎么办
看不到某个功能 / 菜单你的身份没开这个权限，正常。需要就找管理员开。
用着用着被退出了登录过期了（约半天），或管理员改了你的密码 / 权限——重新登录就好。
搜不到型号换个关键词、少打几个字、去掉连字符；或者交给 AI 助手帮你认。
表格里内容显示不全拖表头右边的竖线，把这一列拉宽。
看不到供应商 / 同事的客户销售身份按规矩隐藏，正常现象（防内部抢单、泄露货源）。
AI 助手提示「未配置」服务器还没接 AI 模型，找管理员；其它查询功能照常能用。
利润数字感觉不对 / 想更新导入了新数据、或做完数据治理后，到「利润分析」点一下「重算」。
