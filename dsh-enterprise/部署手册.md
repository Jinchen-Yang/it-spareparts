## 1. 组件清单

| 组件 | 位置 | 说明 |
|---|---|---|
| `dsh-itdata` 插件 | `dsh-plugins/packages/itdata/`（link 进 `~/.dsh/profiles/web`） | 登录桥（权限门）、/itd/ 面板反代、6 个数据工具、设置页（登录/脚本管理）、数据面板标签页 |
| `dsh-itdata-config` 插件 | `dsh-plugins/packages/itdata-config/` | 启动+轮询企业配置端点，锁定唯一模型（写 settings 热生效） |
| 企业 preset `it-data` | `~/.dsh/.agent-presets/it-data/` | 裁剪后的常规 agent（去掉 web 搜索/ralph/workflow/fork） |
| profile patch | `~/.dsh/profiles/web/cordis.patch.yml` | 插件行 + 模型 UI 禁用 + 遥测钉死 + 默认 preset |
| 后端端点 | `backend/app/api/agent_data.py` | `/api/agent/sql`（text2sql 只读+脱敏）、`/schema`、`/call`（业务工具白名单）、`/scripts`（白名单脚本 CRUD/run）、`/dsn`（只读连接） |
| 后端配置端点 | `backend/app/api/system_settings.py` | `/api/system-settings/dsh-llm-config`（admin 或机器密钥） |
| 前端嵌入构建 | `frontend/dist-itd/`（`VITE_BASE=/itd/ VITE_API_BASE=/itd/api npx vite build --outDir dist-itd`） | 面板 SPA |
| 数据库迁移 | `backend/alembic/versions/e5b7d2f4a8c1_sys_dsh_script.py` | `sys_dsh_script` 白名单脚本表 |

## 2. 安装与升级

```bash
# 1) 插件构建 + profile 链接
cd dsh-plugins && pnpm install && pnpm --filter dsh-itdata build && pnpm --filter dsh-itdata-config build
# 2) profile 安装（package.json 已写 link；执行 pnpm install）
cd ~/.dsh/profiles/web && pnpm install
# 3) 后端迁移（发版时）
cd backend && uv run alembic upgrade head
# 4) 前端嵌入构建（前端代码变更后）
cd frontend && VITE_BASE=/itd/ VITE_API_BASE=/itd/api npx vite build --outDir dist-itd
# 5) 重启 dsh web（用户操作；重启后新会话默认 it-data preset）
```

## 3. 后端环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `DSH_RO_DSN` | 可选 | 临时脚本只读连接串；留空则本地脚本模式关闭（`/api/agent/dsn` 返回 501）。生产建议建角色：`CREATE ROLE dsh_ro LOGIN PASSWORD '...' ; GRANT SELECT ON ALL TABLES IN SCHEMA public TO dsh_ro;`（业务表不含 sys_* 的 SELECT） |
| `DSH_CONFIG_TOKEN` | 可选 | LLM 配置下发端点机器密钥；留空则该端点仅 admin 可读 |
| `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` | 企业模型 | 既有的企业 LLM 配置，即 DSH 下发的唯一模型来源 |

## 4. 权限模型（企业视角）

**账号侧（权限中心逐人授权，全部模板默认关闭）：**

| 权限键 | 能力 | 说明 |
|---|---|---|
| `page_chat` | 进入所有 agent 数据通道 | 前置条件 |
| `action_agent_sql` | `db_query`（text2sql，只读+字段脱敏） | 走后端执行，`own_customers_only` 账号整体禁用 |
| `action_agent_dsn_ro` | `run_script` 本地只读模式（PG 只读角色直连） | **不做字段脱敏**，只给完全信任的数据岗 |
| 既有 `action_*` | 白名单写脚本的 `required_action` | 脚本注册时绑定 |

**数据库侧：** 只读角色（DSH_RO_DSN）由 DBA 按 grants 维护；写库永远走服务端白名单脚本（凭据不出服务器，`sys_access_log` 全审计）。

**模型侧：** 唯一 provider `enterprise-llm`（来自后端配置端点），模型选择 UI 已禁用；`ui-settings-models` / `ui-model-selection` 行 disabled。

## 5. 运维要点

- **改白名单脚本**：DSH 设置 → IT 备件系统 → 白名单脚本（仅 admin 可见/可写），或直接调后端 `/api/agent/scripts`。
- **改企业模型**：改后端 .env → 重启后端 → dsh-itdata-config 轮询（默认 60s）自动热更新 settings；改模型密钥不落 DSH settings 明文（进程环境变量）。
- **遥测**：patch 层已钉死 `session-telemetry-otel.mode: DISABLED`（不受 DSH_TELEMETRY_MODE 环境变量影响）。
- **面板**：设置页「打开数据面板」或会话标签页「数据面板」；面板内用 IT 系统账号独立登录（与 DSH 侧 token 同源不同存）。
- **日志**：所有数据工具调用在 `sys_access_log`（action=agent_sql/agent_call/agent_script_*/agent_dsn_ro/agent_schema）。

## 6. 已知边界

- 嵌入面板内 AI 助手页的文件回链（/api/agent/files/*）在 iframe 中按 /itd/api 前缀兼容（ChatPage 已处理）；后端下发的绝对 /api 链接在 iframe 外可用。
- `db_query` 的字段脱敏是键名精确匹配 + 维度名兜底（name_raw/name_normalized）；新派生敏感列需登记进 FIELD_GROUPS（既有 TOOLS-2 护栏）。
- 本机单用户拓扑：登录 token 为进程级单例；改共享拓扑需按 DSH session id 键控（计划文档 §2.1）。

## 8. 双实例隔离（官方版 vs 企业版）

企业定制**不再改动官方版**（`~/.dsh`）——官方版已回滚原样，企业版独立运行：

| | 官方版 | 企业版 |
|---|---|---|
| DSH_HOME | `~/.dsh` | `~/.dsh-itdata` |
| 端口 | 3080 | 3081（可用 `DSH_ITDATA_PORT` 覆盖） |
| 启动 | `dsh web` 或 `dsh --profile web` | `./scripts/dsh-itdata.sh` |
| 模型 | 用户自配（多 provider） | 企业唯一模型（远程下发锁定） |
| 插件 | vislab 等用户自装 | itdata + itdata-config + vislab |
| preset 默认 | standard | it-data |
| 隔离范围 | — | settings / profiles / presets / sessions / storages 全隔离 |

企业版 profile 源文件备份在 `dsh-enterprise/instance/`（`cordis.patch.yml.itdata.bak`、`package.json.itdata.bak`），`~/.dsh-itdata/profiles/web/` 是其安装副本。
