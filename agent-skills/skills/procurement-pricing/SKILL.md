# 采购压价与进货决策

## 触发

- "要进 50 个 XX，目标价多少？" / "供应商报 1700 贵不贵" / "XX 该不该补货 / 补多少"

## 流程

1. 按 [part-identify](../part-identify/SKILL.md) 解析型号（消歧规则同样适用——规格搞错，压价压了个寂寞）。
2. `get_part_overview` 取全景，压价场景重点看四组数据：

   **① 近几次进价及趋势**：近 20 单采购的单价走向（在涨还是在跌——跌价通道里目标价应低于上次成交）。
   注意采购价口径只含计入成本的采购类型（维保等已排除）。

   **② 历史大批量成交价**：批量单比零散单更有参考性——这次要进 50 个，
   就找历史上数量相近的单做锚，而不是拿 2 个一单的零售进价比。

   **③ 库存 + 销售速率 → "还能卖多久"**：
   `还能卖多久 ≈ 当前库存合计 ÷ sales_velocity（近90天日均）`。
   还能卖很久 → 不急，压价底气足、可以等；快断货且动销快 → 给出"为保供可接受的上限"。

   **④ 替代料 = 谈判筹码**：有可互替型号且其行情更低时，明确列出来
   （"XX 可替代，近期进价 ¥Y"），这是压价时最硬的话。

3. 给结论，固定三件套：
   - **目标价区间**（依据 ①② 的事实锚点，写明锚的是哪几单）；
   - **放弃线**（高于多少就不该接，通常参考近期销售行情倒推：进价高于近期成交参考价的 X% 就没毛利空间）;
   - **进货量参考**（依据 ③：按当前动销，50 个够卖多久；滞销品提示砍量）。

## 回答示例

> "要进 50 片 V100 PCIE 16G，目标价多少？"

✅ "目标区间 ¥7,200–7,500，放弃线 ¥8,000。依据：近 3 次进价 7,800→7,500→7,400（下行）；
去年 11 月有一单 30 片批量价 7,200 可作锚；T4 可部分替代且行情 ¥5,xxx 可作筹码。
当前库存 18 片、近 90 天出 22 片——50 片约够 7 个月，量偏大，可考虑首批 30 片。
销售端近期成交参考价 ¥8,9xx，进价高于 8,000 毛利空间就太薄了。"

## 边界与变通

- **无采购历史的新型号**：如实说库内无进价记录，给销售端行情倒推的上限参考，标注"无历史进价锚点"。
- **价格趋势剧烈波动**（GPU 类常见）：明说波动大、历史锚点失效快，建议小批量试单。
- **供应商报价对比**："1700 贵不贵"→ 和最近 N 笔进价 + 近 15 天采购窗口（均/低/高）比，给相对位置，
  不替采购拍"买/不买"。
- 🔴 所有数字来自工具返回；"行业一般价"这种凭常识的数字不许给。
- redirected_from 照例说明（防止下采购单写了墓碑 PN）。
