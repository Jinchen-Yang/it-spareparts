# 整机配置拆解报价

## 业务背景

客户发来一份整机/服务器配置（如"1台服务器：2×Intel Xeon Gold 6330、8×32G DDR4 RECC、
4×1.92T NVMe、双电源…"），销售要拆成单件去查 PN 和最近采购价，再发采购询价或自己加点直卖。
**拆件是你的核心价值**——靠硬件常识把自然语言配置翻译成可询价的部件清单。

## 流程

1. **`read_document` 读全文**（Word/PDF/txt/Excel/图片均可；图片/扫描件自动走视觉识别，
   视觉模型未配置时会返回提示——此时请用户发文字版）。
2. **自己拆件**：把整机拆成部件清单，每件 **品牌 + 型号 + 规格 + 数量**。
   - 翻译规则示例："8×32G DDR4 RECC 3200" = 8 根 32GB DDR4 ECC REG 3200MHz 内存；
     "双电源" = 2 个该机型适配电源模块；"2U 机架式" 属于准系统特征不单列。
   - 多台整机：数量 = 单台用量 × 台数，并在清单里注明。
   - 拆不准的部件**也要列出来**，标"待人工确认规格"——漏件比错件更糟（漏了就没人询价）。
3. **`lookup_prices_bulk` 批量查** PN + 近 15 天采购价 + 库存（>60 件分批）。
4. **消歧按批量规则**：纯规格件（如"32G DDR4"无品牌）常 ambiguous——候选列进备注让用户/采购选，
   **不要硬选一个**。
5. **`write_report` 生成美化报价单**（不是 write_excel）。列建议：
   `序号 / 部件 / 品牌 / 型号规格 / 数量 / 匹配PN / 匹配状态 / 近15天采购均价(及区间) / 库存 / 近期成交参考价 / 备注`，
   `money_cols` 标金额列。
   - **近期成交参考价** = 工具返回的 `ref_sale_price`（口径见
     [data-dictionary](../../references/data-dictionary.md)）；
     🔴 **不替销售算"建议售价"**——最终加价他自己把握。同时保留采购价列供发采购询价。
   - 15 天内无采购的件：用最近一次采购价，备注标"非15天内，最近 ¥X 于 YYYY-MM-DD"。
   - 需确认/未找到的行会被 write_report 自动标橙/红。
6. **回复**：`download_url` + 汇总（共几件 / 几件已匹配 / 几件需确认规格或型号 /
   合计预估成本与近期成交参考价合计）。
   🔴 这份报价单含内部采购价列——提醒用户**发客户前删除内部列**。

## 边界与变通

- **配置单里有服务/保修项**（"3年上门服务"）：列入清单但备注"服务项，库内无对应备件"，不强行匹配 PN。
- **品牌整机型号**（如 Dell R740 配置）：准系统按整机型号查；部件按各自型号查，
  没写明部件型号的（"480G SSD×2"）按规格查并预期 ambiguous。
- **图片模糊/识别不全**：把识别出的部分先列出来，明确说哪部分没读清，请用户补文字。
- **多方案对比**（客户给两套配置）：分别拆、同一张报表分块或两个 sheet，汇总分别给。
- 🔴 合计金额只汇总工具返回的真实价格；缺价的件在合计里注明"另有 N 件缺价未计入"，不要拿常识价补。
